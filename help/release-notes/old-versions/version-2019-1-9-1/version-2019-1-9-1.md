# 버전 2019.1 (9.1)

**Substance Designer 2019.1**&#x200B;은(는) Substance 엔진의 기능을 더 확장하고 새로운 필터를 추가로 확장하기 위해 새로운 업데이트를 제공합니다.

## 주요 기능

### 새 값 프로세서 노드

![](version-2019-1-9-1.resources/version-2019-1-9-1-01.png)

Substance 엔진은 이제 버전 7이며 합성 그래프 내에 새로운 개념의 &quot;값&quot;을 제공합니다. 값은 숫자이며 텍스처가 아니므로 함수 그래프와 합성 그래프를 통해 노드 간에 공유할 수 있는 다양한 계산을 수행하는 데 사용할 수 있습니다. Value Processor 노드는 입력 이미지를 읽고 단일 출력 값을 계산할 수 있습니다.

Value Processor 노드만 있는 것이 아니라 그래프 전체에서 정보를 전송할 수 있습니다. 일부 변경 및 추가가 이루어졌습니다.

* 출력 노드에는 값을 직접 제공할 수 있으며 더 이상 반드시 이미지가 제공되지는 않습니다.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-02.png)
* 그래프에서 값을 쿼리할 수 있도록 이름이 &quot;Input Value&quot;인 새 **입력 노드**&#x200B;가 추가되었습니다.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-03.png)
* 이제 노드에는 &quot;Input Values&quot;라는 매개변수 아래에 노드 자체에 대한 입력 값을 생성하는 데 사용할 수 있는 새 범주가 있습니다.\
  입력 값은 &quot;Get&quot; 노드를 통해 함수 그래프 내에서 참조될 수 있습니다.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-04.png)

>[!NOTE]
>
> 모든 주요 Substance 엔진 변경과 마찬가지로 호환성 모드는 이전 버전(기본적으로 새 버전 6)으로 설정됩니다. 즉, 호환되지 않는 노드는 그래프에서 노란색 테두리를 갖습니다. 노란색 테두리를 비활성화/숨기려면 기본 설정의 엔진 버전을 프로젝트 설정을 통해 최신 버전으로 변경하기만 하면 됩니다 .
> 
> ![](version-2019-1-9-1.resources/version-2019-1-9-1-05.png)

### 베이커에서 Optix 지원

![](version-2019-1-9-1.resources/version-2019-1-9-1-06.jpg)

Substance Designer의 마지막 업데이트는 호환 RTX 호환 하드웨어에서 GPU 광선 추적을 수행 할 수 있는 DXR을 도입했다. 이제 Linux에서도 다른 Nvidia의 GPU에서 광선 추적을 사용할 수 있는 [Optix](https://developer.nvidia.com/optix)에 대한 지원을 추가했습니다. Optix를 사용할 때 일반 CPU 광선 추적보다 **5배 이상 더 빨리** 구울 수 있습니다.

다음은 이 변경의 영향을 받는 베이커 목록입니다.

* 메시에서 주변 오클루전
* 메쉬에서 구부러진 수직
* 메쉬에서 Thickness

두 개의 뒷면 중 하나를 비활성화하려면 기본 환경 설정(**편집 > 환경 설정**)과 Bakers 설정으로 이동합니다.

![](version-2019-1-9-1.resources/version-2019-1-9-1-07.png)

>[!NOTE]
>
> 기능에 액세스하려면 **다음 드라이버로 업데이트**:
> 
> * Nvidia 10XX 및 20XX GPU : **드라이버 430.39**(DXR 및 Optix 모두와 호환)
> * Nvidia 9XX 이상 : **d** **rivers 419.67 또는 430.39**(드라이버 425.31에 Optix 관련 문제가 있음)
> 
> DXR은 [GeForce GTX 10xx GPU](https://www.nvidia.com/en-us/geforce/news/geforce-gtx-dxr-ray-tracing-available-now/)&#x200B;(최신 드라이버 포함)에서도 사용할 수 있습니다. DXR에서 작업을 수행하려면 Windows가 최신 상태여야 합니다. 자세한 내용은 [이 페이지](../../../best-practices/performance-optimization/performance-optimization-guidelines.md)를 참조하십시오.

### OBJ 메시의 로드 시간 개선

![](version-2019-1-9-1.resources/version-2019-1-9-1-08.jpg)

이 릴리스에서는 3D 메시 로딩 시간을 줄이기 위해 **obj** 파일 판독기를 개선했습니다. 로딩 시간이 최대 3배 빨라졌습니다. 특히 UV와 표준이 정의되지 않은 메시의 경우 더욱 빨라졌습니다.

이 성능 향상은 베이커 및 3D 뷰 모두에 영향을 미칩니다.

### 개선된 Python 플러그인 시스템

![](version-2019-1-9-1.resources/version-2019-1-9-1-09.png)

이번 업데이트를 통해 스크립팅 시스템에 새로운 기능이 많이 추가되었습니다.

* **Qt의 지원** : 나머지 응용 프로그램의 동일한 스타일을 따르는 사용자 지정 UI를 빌드할 수 있습니다. 또한 사용자 정의 UI는 이 새로운 시스템과 훨씬 쉽게 통합될 수 있습니다. Tkinter는 이제 더 이상 사용되지 않습니다.
* **콜백 함수** : 이제 콜백 함수를 등록할 수 있습니다. 지금은 파일 열기 및 저장과 UI 요소 생성만 포함합니다. 향후 콜백이 추가로 추가될 예정입니다.
* **스레딩**: 이제 플러그인이 스레드를 만들어 백그라운드 처리를 수행하거나 OS 이벤트(예: 네트워크 연결)를 기다릴 수 있습니다.

자세한 내용은 Substance Designer 내의 **도움말 > Python API 설명서** 메뉴 항목을 통해 액세스할 수 있는 API의 변경 로그를 살펴보십시오.

### 새 콘텐츠

또한 기본 라이브러리에서 사용할 수 있는 몇 개의 새 노드가 있으며, 그 중 일부는 이제 새로운 값 프로세서 노드 로 구동됩니다.

* **색인에 Flood Fill**\
  Flood Fill 노드의 모양에 고유한 색인을 할당합니다.\
  아래 예에서 Pixel Processor 노드는 모양에 입력된 값 과 일치하고 그 결과로 마스크를 출력합니다.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-10.gif)
* **Non Uniform Directional Warp**\
  이미지 입력에서 강도와 각도가 샘플링되는 위치에 방향 뒤틀기를 적용합니다.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-11.gif)
* **다중 방향 뒤틀기**\
  입력 이미지를 다양한 방향으로 여러 번 뒤틀기

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-12.gif)
* **높이 돌출**\
  지정된 Height의 직교 3D 렌더링을 생성합니다. 카메라 보기는 위치 gizmo로 제어할 수 있습니다.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-13.gif)
* **최소/최대 값**\
  입력 이미지의 최소 및 최대 픽셀 값을 반환합니다.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-14.png)

>[!WARNING]
>
> 이 릴리스에서는 더 이상 CentOS 6.x를 지원하지 않습니다. 최신 버전의 Substance Designer을 사용하려면 CentOS 7.x로 업그레이드하십시오.
