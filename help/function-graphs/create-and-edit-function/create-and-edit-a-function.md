# 함수 만들기 및 편집

## 함수 만들기

함수를 만들려면 함수 아이콘 ![](../../assets/image2017-3-7-17-10-8.png)을(를) 클릭하고 &quot;**빈 함수**&quot;을(를) 선택하면 됩니다.

![](../../assets/image2017-3-7-17-8-37.png)

## 함수 편집

함수를 만든 후에는 함수 아이콘을 다시 클릭하거나 드롭다운 목록에서 편집을 선택하여 수정할 수 있습니다.

![](../../assets/image2017-3-7-17-11-42.png)

그런 다음 그래프의 함수 모드로 들어갑니다.

## 함수 그래프

함수 그래프는 노드 편집기를 사용하는 Designer의 다른 그래프 유형과 동일한 방식으로 작동합니다.

## 노드 만들기

그래프를 마우스 오른쪽 단추로 클릭하고 &quot;요소 추가&quot;를 선택하거나 스페이스바를 눌러 노드를 만들 수 있습니다.

![](../../assets/capture-d-e-cran-2015-02-04-10-05-16.png){width="600px"}

## 출력 설정

Substance 그래프와 반대로 함수에 &quot;출력&quot; 노드가 없으므로 그래프에서 함수 출력을 어느 노드로 지정해야 합니다.

노드를 마우스 오른쪽 단추로 클릭하고 <b>&quot;출력 노드로 설정&quot;을 선택하여 출력을 설정할 수 있습니다.</b>

출력으로 설정된 노드는 노란색이 됩니다.

>[!NOTE]
>
> **출력 형식**
> 
> 출력으로 설정하려는 노드에는 해당 노드가 제어하는 매개 변수와 동일한 값 유형을 보유해야 합니다. 그렇지 않으면 &quot;출력 노드로 설정&quot; 옵션이 회색으로 표시됩니다.

>[!WARNING]
>
> 작동하려면 함수에 출력이 있어야 합니다. 함수에 출력 세트가 없는 경우 그래프에 경고가 표시됩니다.
