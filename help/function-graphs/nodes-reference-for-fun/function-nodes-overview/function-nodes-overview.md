# 함수 노드 개요

이 페이지에서는 모든 함수 노드에 대한 전체 개요를 제공하고 함수 데이터 형식에 사용되는 색상 코딩에 대해 설명합니다. 자세한 내용을 보려면 여기를 클릭하십시오.

이러한 함수 노드는 그래프 함수 편집기를 마우스 오른쪽 단추로 클릭하고 요소를 선택하거나 함수에서 스페이스바 또는 탭을 누르거나 라이브러리의 함수 섹션을 통해 액세스할 수 있습니다.
