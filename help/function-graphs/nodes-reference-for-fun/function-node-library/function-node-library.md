# 함수 노드 라이브러리

[atomic nodes](../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/atomic-function-nodes.md) 외에도 Designer에서는 미리 만든 Substance 함수 그래프를 인스턴스 노드로 제공합니다. 그들은 워크플로우를 가속화 하 고 벡터 또는 색상 작업, 값을 다시 매핑, 더 고급 대수를 수행 할 수있는 더 많은 기능을 제공 하는 많은 도구를 제공합니다.

이러한 도구는 다음과 같은 여러 범주로 정렬됩니다.

<a name="sdf-functions"></a>

## SDF 기능

이러한 노드를 사용하면 전용 **SDF 함수** 매개 변수를 사용하여 [모양 스플래터 v2](../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) 및 [3d 뷰어](../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/3d-viewer/3d-viewer.md) 노드에서 3D 모양을 생성하는 데 사용할 수 있는 SDF 함수를 제작할 수 있습니다.

>[!INFO]
> 
> SDF 함수와 관련된 개념 및 작업 과정에 대해 자세히 알아보려면 전용 페이지로 이동하십시오. [SDF 함수 작업](function-nodes-sdf-functions/working-with-sdf-functions.md)
