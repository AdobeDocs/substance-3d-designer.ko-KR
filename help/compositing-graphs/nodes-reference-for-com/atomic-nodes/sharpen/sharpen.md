## 설명

선명 효과 노드는 입력에 대해 선명 효과 작업을 수행합니다. 이미지에 선명한 느낌을 마지막으로 적용하기 위한 유용한 노드입니다.

명칭은 다르지만 수학적으로는 Photoshop의 언샵 마스크와 매우 유사하다. 기본 색상 지도와 같은 것에는 효과적이지만 일반 지도나 금속 지도와 같은 지도에서는 피해야 합니다.

## 입력

<b>입력</b> *색상/회색 음영*(기본)\
선명하게 해야 하는 이미지입니다.

## 매개변수

<b>강도</b> *부동*\
선명하게 하기 효과의 강도를 설정합니다.

<b>펀치스루 Alpha</b> *부울*(색상 이미지가 <b>입력</b>에 연결된 경우 사용 가능)\
이미지의 알파 채널을 선명하게 할지, 아니면 그대로 유지할지 결정합니다.
