## 설명

미리 정의된 일부 **순수** 금속에 대해 올바른 반사 색상을 반환하기 위한 빠른 사전 설정 도우미 노드입니다. 금속 모델의 기본 색상에서 사용하거나 Specular/광택 모델의 Specular 채널에서 사용할 수 있습니다.

이 노드는 순수한 금속의 시작점을 원하는 경우 유용하며 차트에서 색상 피킹을 방지할 수 있습니다.

## 매개변수

* **금속 색상**: *금, 은, 알루미늄, 철, 구리, 티타늄, 니켈, 코발트, 백금*&#x200B;미리 정의된 금속 값을 선택합니다.
