# PBR 유틸리티

이 범주에는 PBR 재질 작업을 위한 도우미 노드가 포함되어 있습니다. 이는 Specular 광택 뿐만 아니라 금속 거칠기 PBR 작업 과정에 사용하기 위한 것입니다. 모든 노드는 다중 채널 재질을 위한 것이며, 채널은 하나 또는 둘 모두의 워크플로우를 지원하기 위해 활성화(비활성화)될 수 있다.

특히 유용한 노드는 다음과 같습니다.

* [PBR BaseColor/Metallic Validate](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/pbr-basecolor-metallic/pbr-basecolor-metallic-validate.md)
