## 설명

Specular PBR 모델을 사용할 때 Specular 값에 대한 유틸리티 &quot;사전 설정&quot; 노드.

정확한 값을 시작점으로 빠르게 가져와 차트에서 색상을 선택하지 않도록 하는 데 유용합니다.

## 매개변수

* **Specular F0**: *플라스틱, 나무, 돌, 벽돌, 모래, 콘크리트, 직물, 녹슨 금속, 물, 얼음, 유리, 맞춤 IOR*&#x200B;미리 정의된 Specular 범위를 선택합니다.
* **Specular 범위**: *0.01 - 1.0*&#x200B;선택한 사전 설정의 범위 내에서 Specular 값을 조정합니다. 약간의 수정이 허용됩니다.
* **IOR**: *1.0 - 5.0*&#x200B;사용자 지정 IOR로 설정된 경우에만 사용할 수 있습니다. 자신의 가치를 선택합니다.
