# 효과(재질)

이 범주에는 [풍화](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/weathering/weathering.md) 노드의 작동 방식과 유사하게 완전히 본격적인 재질 효과를 생성하는 노드가 포함되어 있지만, 주된 차이점은 이러한 효과 노드가 모든 재질을 입력으로 사용할 수 있다는 것입니다. 또한 베이킹된 맵 입력(대부분 Heightmap)이 필요합니다.

두 가지 좋은 예는 [수위](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/water-level/water-level.md)와 [Snow 표지](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/snow-cover/snow-cover.md)입니다.
