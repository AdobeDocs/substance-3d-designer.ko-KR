# 자료 필터

재질 필터는 전체 재질 입력과 함께 작동하는 노드입니다. 여러 채널의 조합으로 [링크 만들기 모드](../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md)를 통해 가장 잘 사용됩니다. 기본 색상 또는 표준과 같은 단일 채널이나 간단한 흑백 마스크가 아닌 전체 PBR 재질로 작업할 때는 항상 [재질 필터] 범주를 사용하려고 합니다.

이 범주는 다음과 같은 여러 하위 범주로 구성됩니다.

* [1-클릭](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/1-click/1-click.md)\
  Bitmap2Material만 포함합니다.
* [효과](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/effects-material.md)\
  화려한 올인원 소재 효과
* [변형](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/transforms-material/transforms-material.md)\
  다중 채널 변환 도우미.
* [혼합](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/blending-material.md)\
  다중 채널 혼합 노드.
* [PBR 유틸리티](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/pbr-utilities.md)\
  PBR 도우미 노드 및 도구입니다.
* [스캔 처리](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/scan-processing/scan-processing.md)\
  특히 포토스캔 텍스처를 위한 도구
