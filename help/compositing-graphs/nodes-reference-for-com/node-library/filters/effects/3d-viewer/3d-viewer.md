## 설명

사용자 정의 카메라 및 환경 조명을 사용하여 함수 그래프로 정의된 교차 장면이나 지정된 SDF에 대한 3D 렌더링을 계산합니다.<br><br>이 SDF 함수는 [모양 스플래터 v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) 노드에서 사용할 [노드](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions)를 작성하고 시각화하는 데 유용합니다.<br><br>도우미를 사용하여 공간에서 모양의 주요 특성을 시각화할 수 있습니다.<br><br>고급 사용자의 경우 사용자 지정 기능을 작성하여 픽셀당 카메라 및/또는 3D 렌더링을 설정할 수 있습니다.

## 입력

|                            |                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:---------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>환경</b> *색상* | 무한 구에 투사되어야 하는 이미지는 장면의 환경으로 사용되며 환경 조명에 사용됩니다.<br><br>투영은 <i>정방형</i>입니다. 이 투영은 라이브러리의 <b>3D 보기 > HDRI 환경</b> 범주에서 사용할 수 있는 Designer의 기본 환경 맵에서 사용됩니다.<br><br>연결하지 않으면 기본 환경이 사용됩니다.<br><br><i>팁:</i> 정확한 조명을 위해 HDR 이미지(32비트)를 사용합니다. |
| <b>입력 1</b> *색상* | <b>출력</b> 매개 변수가 &#39;Custom&#39;으로 설정된 경우 <b>사용자 지정 출력</b> 함수 그래프에서 샘플링될 수 있는 이미지입니다.<br><br>이 이미지에서 샘플링하려면 &#39;Image input 0&#39;으로 설정된 [샘플 색상](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md) 노드를 사용하세요. |
| <b>입력 2</b> *색상* | <b>출력</b> 매개 변수가 &#39;Custom&#39;으로 설정된 경우 <b>사용자 지정 출력</b> 함수 그래프에서 샘플링될 수 있는 이미지입니다.<br><br>이 이미지에서 샘플링하려면 &#39;Image input 1&#39;로 설정된 [샘플 색상](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md) 노드를 사용하세요. |

## 출력

|               |                                                                                                                                                                                                                                    |
|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>출력</b> | <b>출력</b> 매개 변수에서 선택한 AOV를 사용하는 렌더링된 장면입니다.<br><br><i>참고:</i> 일부 AOV에서 정확한 판독을 위해 2D 보기가 선형 색상 공간을 사용하고 노드가 HDR 32비트 출력 형식을 사용하는지 확인하십시오. |

<a name="parameters"></a>

## 매개변수

|                                               |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:----------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>장면 유형</b> *정수* | 렌더링할 표면 및 모양을 설명하는 데 사용되는 함수 유형:<br>- <b>SDF:</b> 복잡한 모양을 설명할 수 있는 SDF(Signed Distance Field) 함수를 사용합니다.<br>- <b>교차:</b> 단순한 기본 모양만 필요한 경우 더 빠른 교차 함수를 사용합니다. |
| <b>SDF 장면</b> *부동* | 서명된 거리 필드 (SDF) 는 장면의 표면 및 모양을 설명합니다.<br><br>라이브러리의 [SDF 함수](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions) 범주에 있는 노드를 사용하여 함수를 만드십시오. |
| <b>장면 교차</b> *부동* | 장면의 표면 및 모양을 설명하는 교차 함수입니다.<br><br>기본 요소 및 연산자에 대한 교차 함수는 <b>3d_functions.sbs</b> 라이브러리 패키지의 <b>3d_intersection</b> 폴더에서 사용할 수 있습니다.<br><br><i>팁:</i> 라이브러리에서 탐색기로 SDF 노드를 삭제하여 패키지에 액세스할 수 있습니다. |
| <b>출력</b> *정수* | 노드에서 출력해야 하는 3D 렌더링 유형(일반적으로 AOV(임의 출력 변수)입니다.<br><br>사용 가능한 AOV는 다음과 같습니다.<br>- <b>아름다움:</b> 아트 지향 색상 및 효과와 함께 3D 렌더링의 최종 결과.<br>- <b>표준 WS:</b> 장면에 있는 모양의 세계 공간 표준입니다.<br>- <b>표준 TS:</b> 장면에 있는 모양의 탄젠트 공간 표준입니다.<br>- <b>위치:</b> 장면에 있는 모양 표면의 세계 공간 위치입니다.<br>- <b>거리:</b> 카메라에서 카메라까지의 원시 거리입니다. 장면의 모양<br>- <b>깊이:</b> 평면이 항상 카메라를 향하는 카메라 대상 평면에서 모양의 부호 있는 거리입니다.<br>- <b>색상:</b> 모양의 기본 색상(&#39;색상 설정&#39; 노드를 사용하여 장면 함수의 모양에 색상을 지정)<br>- <b>재질 ID:</b> 모양 표면에 적용된 재질 ID(&#39;재질 ID 설정&#39; 노드를 사용하여 장면 함수의 모양에 재질 ID를 지정)<br>- <b>구 추적 단계:</b> 모양의 표면을 정의하는 데 필요한 단계의 양을 시각화합니다. 값이 더 밝을수록 더 많은 단계가 필요합니다.<br>- <b>사용자 지정:</b> 픽셀당 렌더링 색상을 계산하는 사용자 지정 함수를 작성합니다.<br><br><i>참고:</i> 일부 AOV에서 정확한 판독을 위해 2D 보기에서 선형 색상 공간을 사용하고 노드가 HDR 32비트 출력 형식을 사용하는지 확인하십시오. |
| <b>사용자 지정 출력</b> *Float4* | 렌더링된 장면의 픽셀당 RGBA 색상을 Float4 값으로 정의하는 함수 그래프.<br><br>사용 가능한 변수:<br>- <code>scene.position</code> (Float3) 장면 표면의 세계 공간 위치입니다.<br>- <code>scene.normal</code> (Float3) 장면 표면의 월드 스페이스 표준입니다.<br>- <code>scene.hit</code> (부울) 표면에 카메라 레이가 도달하면 &#39;True&#39;를 반환합니다.<br>- <code>view.origin</code> (Float3) 카메라 보기의 픽셀당 월드 공간 위치입니다.<br>- <code>view.direction.</code> (Float3) 투영 모드에 따른 카메라 뷰의 픽셀당 순방향 벡터. (E.g. 원근 또는 맞춤법)<br>- <code>material.color</code> (Float3) 장면 표면의 기본 색상입니다.<br>- <code>material.metalness</code> (부동) 장면 표면의 금속입니다.<br>- <code>material.roughness</code> (부동) 장면 표면의 거칠기입니다.<br>- <code>material.id</code> (정수) 장면 서피스의 재료 ID입니다.<br><br>다음 [색상 샘플링](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md) 노드 슬롯을 선택하여 노드의 이미지 입력을 샘플링할 수 있습니다.<br>- <b>이미지 입력 0</b>은 입력 1을 샘플링합니다.<br>- <b>이미지 입력 1</b>은 입력 2를 샘플링합니다. |
| <b>환경 회전</b> *부동* | <b>환경</b>의 회전(회전 수)입니다. |
| <b>배경 모드</b> *정수* | 모양 표면이 보이지 않는 곳에 그려진 장면의 배경 소스를 지정합니다.<br><br>- <b>색상:</b> 평평한 &#39;배경색&#39;.<br>- <b>환경:</b> &#39;환경&#39; 입력에 제공된 이미지로, 정방형 투영을 사용하여 무한한 구에 적용됩니다.  입력이 연결되지 않은 경우 기본 환경이 사용됩니다. |
| <b>배경색</b> *Float4* | 장면의 배경으로 사용되는 단색입니다. |
| <b>IBL 샘플</b> *정수* | 카메라 샘플당 수행된 조명 샘플의 양입니다.<br><br>값이 높을수록 성능이 저하되어 더 부드럽고 정확한 조명을 얻을 수 있습니다. |
| <b>카메라 샘플</b> *정수* | 픽셀 당 수행되는 카메라 샘플의 양입니다.<br><br>이 매개 변수는 앤티 앨리어싱의 품질과 필드 효과의 깊이에 영향을 줍니다.<br><br>값이 높을수록 성능이 저하되지만 이미지의 노이즈가 줄어듭니다. |
| <b>광선 행진 단계</b> *정수* | 구 추적 프로세스에서 수행된 단계의 양, 즉 모양의 표면을 감지하고 그리는 데 사용되는 광선 마칭 기법입니다.<br><br>값이 높을수록 성능이 저하되지만 정확하고 일관된 표면(특히 복잡한 모양의 경우)이 생성됩니다.<br><br><i>팁:</i> <b>출력</b> 매개 변수를 &#39;구 추적 단계&#39; AOV로 설정하여 추가 단계가 필요한 모양의 영역을 시각화하십시오. 이러한 영역은 먼저 단계의 양을 줄여 영향을 받습니다. |
| <b>보조 광선 행진 단계</b> *정수* | 구 추적 프로세스에서 수행한 단계의 양으로 확산 및 Specular 오클루전을 계산하여 기울어진 그림자를 그립니다.<br><br>값이 높을수록 성능이 저하되어 그림자가 더 정확해집니다. |
| <b>카메라 모드</b> *정수* | 장면을 렌더링 이미지에 투영하는 방법:<br><br>- <b>원근감:</b> 이 투영은 깊이를 전달하고 필드 깊이와 같은 렌즈 효과를 활성화합니다.<br>- <b>직교:</b> 이 투영은 장면을 병합하고 깊이를 무효화합니다.<br>- <b>사용자 정의 함수:</b> 함수 그래프를 작성하여 사용자 정의 카메라를 설정합니다. |
| <b>카메라 함수</b> *Float3* | 카메라의 변환을 정의하는 함수 그래프 이 설정은 사용자 정의 카메라를 설정하는 데 사용할 수 있습니다.<br><br>함수는 다음 변수를 <b>설정</b>해야 합니다.<br>- <code>view.origin</code> (Float3) 카메라 보기의 픽셀당 월드 공간 위치입니다.<br>- <code>view.direction.</code> (부동 3) 투영 모드에 따른 카메라 뷰의 픽셀당 순방향 벡터. (E.g. 원근감 또는 직교)<br><br>다음 변수를 <b>get</b>:<br>- <code>camera.origin에 사용할 수 있습니다.</code> (부동 3) 카메라의 월드 공간 위치입니다. (camera.direction * camera_distance + camera.target)<br>- <code>camera.direction</code> (부동3) 카메라의 월드 공간 방향(즉, 카메라의 Y-포워드 벡터).<br>- <code>camera.right</code> (부동 3) 카메라의 X-오른쪽 벡터.<br>- <code>camera.up</code> (부동3) 카메라의 Z-up 벡터입니다.<br>- <code>camera.target</code> (부동 3) 카메라 대상의 세계 공간 위치입니다. |
| <b>UV 위치</b> *부동2* | 2D 이미지 공간에서 <b>대상 위치</b>를 선회하는 카메라 위치와 방향을 유추하는 데 사용되는 위치입니다.<br><br><i>팁:</i> 이 매개 변수는 노드를 선택할 때 2D 보기에서 사용할 수 있는 <i>위치 기즈모</i>를 사용하여 직관적으로 조정할 수 있습니다. |
| <b>FOV</b> *부동* | 확대/축소 계수에 영향을 주는 직교 카메라의 FOV(시야). |
| <b>초점 거리</b> *부동* | 필드 효과의 확대/축소 계수와 깊이에 영향을 주는 카메라의 초점 거리. |
| <b>대상과의 거리</b> *부동* | 카메라가 <b>대상 위치</b>에서 정지해야 하는 거리입니다.<br><br>이 옵션을 조정하면 카메라가 대상 방향으로 이동합니다. |
| <b>대상 위치</b> *Float3* | 카메라가 항상 향하는 카메라 대상 위치입니다. |
| <b>토네마퍼</b> *정수* | 장면 렌더링에 적용해야 하는 톤 매핑 알고리즘입니다.<br><br>- <b>없음(Raw)<br>- <b>sRGB</b><br>- <b>AgX</b><br>- <b>ACE</b> |
| <b>필드 깊이 사용</b> *부울* | 원근감 카메라에 대한 &#39;필드 깊이&#39; 카메라 렌즈 효과를 시뮬레이션합니다.<br><br><b>F 숫자</b> 및 <b>초점 거리</b> 매개 변수를 사용하여 효과의 조리개와 초점을 각각 조정합니다.<br><br>결과는 <b>초점 거리</b>에도 영향을 줍니다. |
| <b>F-번호</b> *부동* | 카메라의 <i>조리개</i>.<br><br>값이 낮을수록 <i>필드 깊이</i>이 짧아집니다. 즉, 개체가 선명해지는 거리 범위가 짧아지고 해당 범위에서 멀어질수록 더 강한 흐림 효과가 적용됩니다. |
| <b>초점 거리</b> *부동* | 초점의 거리를 카메라에서 전방 벡터를 따라 떨어진 거리로 설정합니다.<br><br>해당 거리 범위 내의 표면은 선명하게 나타나며, 해당 범위, 즉 <i>필드 깊이 </i>은(는) <b>F-숫자</b>로 정의됩니다. |
| <b>노출(EV)</b> *부동* | 카메라 센서에 닿는 빛의 양, 즉 렌더링에서 조명의 강도.<br><br>값이 낮을수록 렌더링되는 장면이 더 어두워집니다.<br><br>EV(노출 값)는 구체적으로 카메라 센서가 <i>노출</i>되는 빛의 양을 나타냅니다. |
| <b>기본 색상</b> *Float3* | 해당 색상이 SDF 또는 교차 함수로 정의되지 않은 서피스의 기본 기본 색상입니다. |
| <b>거칠음</b> *부동* | 해당 값이 해당 SDF 또는 교차 함수에 의해 정의되지 않은 서피스의 기본 거칠기 값입니다. |
| <b>금속성</b> *부동* | 해당 값이 해당 SDF 또는 교차 함수에 의해 정의되지 않은 서피스의 기본 금속도 값 |
| <b>도우미 불투명도</b> *부동* | 3D 도우미의 불투명도. 여기서 값이 낮을수록 도우미 가 희미해집니다. |
| <b>테두리 프레임</b> *부울* | 전체 장면의 경계를 정의하는 6면 케이지의 시각화. 가장 작은 크기로 장면을 포함하는 것이 좋습니다.<br><br>테두리 프레임 크기</b> 매개 변수를 사용하여 케이지의 크기를 조정합니다.<b><br><br>프레임 밖의 색상 입히기</b> 매개 변수를 사용하면 해당 케이지 외부의 표면을 쉽게 시각화할 수 있습니다. 이는 [모양 스플래터 v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) 노드에서 해당 장면을 사용한 결과에 영향을 줍니다. <b>(&#39;테두리 프레임 크기&#39; 도구 설명 참조) |
| <b>테두리 프레임 크기</b> *Float3* | 테두리 프레임의 XYZ 크기를 설정합니다.<br><br>프레임을 장면에 조정한 다음 동일한 값을 [모양 스플래터 v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) 노드의 <b>SDF 바운드 프레임 크기</b> 매개 변수에 적용하여 장면의 모든 모양이 해당 노드에 의해 올바르게 포함되고 그려지도록 합니다. |
| <b>프레임 밖으로 색상화</b> *부울* | 테두리 프레임 외부의 표면에 빨간색을 적용합니다.<br><br>장면을 테두리 프레임에 완전히 포함하는지 확인하는 데 도움이 됩니다. |
| <b>축</b> *부울* | 장면의 XYZ 축을 장면의 원점에서 시작하는 색상이 적용된 선으로 시각화한 것입니다. |
| <b>격자</b> *부울* | XY축에 배치된 그리드의 시각화로서 X와 Y에 있는 한 셀의 크기는 장면 단위이다. |
| <b>도우미 변형</b> *부울* | 마지막으로 적용된 순환에 대한 시각화입니다.<br><br>시각화에는 회전 축 방향 벡터를 나타내는 <br>- <b>화살표</b>가 포함되며, 각 세계 공간 축의 두께 뒤에 색상이 지정됩니다.<br>- <b>회전 각도를 나타내는 호</b>로, 해당 색상과 일치하는 화살표와 직각을 나타냅니다. |
| <b>SDF 등치선</b> *부울* | SDF(Signed Distance Field) 함수 아이소라인의 색상 시각화.<br><br>아이소라인은 지정된 Height에서 XY 평면에 있는 모양의 <i>거리 필드</i>를 나타내는 선을 정기적으로 반복합니다.<br><br>SDF 함수가 정의한 <i>공간의 균일성</i>을 확인하는 데 유용합니다.<br><br><b>SDF 아이소라인 빈도</b> 및 <b>SDF 아이소라인 위치</b> 매개 변수를 사용하여 아이소라인의 밀도와 Height을 조정합니다. |
| <b>SDF 격리 빈도</b> *부동* | 지정된 거리 내에서 아이소라인 반복의 양입니다.<br><br>값이 높을수록 선이 더 촘촘해지고 얇아집니다. |
| <b>SDF 격리 위치</b> *부동* | XY 평면의 월드 공간 Height은 아이소라인을 그리는 데 사용되었습니다.<br><br>다양한 높이에서 모양의 거리 필드를 확인할 때 사용합니다. |
| <b>분. 적중 거리</b> *부동* | SDF 광선 행진 프로세스에 대해 적중으로 변환되는 최소 거리를 정의합니다.<br><br>값이 낮으면 광선 행진 단계의 수가 늘어납니다. |
