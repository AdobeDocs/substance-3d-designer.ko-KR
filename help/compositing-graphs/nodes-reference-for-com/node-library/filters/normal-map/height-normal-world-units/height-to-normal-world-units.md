## 설명

변환 중에 실제 단위를 사용하는 고급 Height-일반 변환 노드입니다.

소스 Heightmap의 크기를 알고 스캔한 재질 등을 사용하여 작업하는 경우와 같이 가장 정확한 변환을 수행하려는 경우에 유용합니다.

## 매개변수

* **표면 크기(cm)**: *0.0 - 1000.0*&#x200B;입력 Heightmap Dimension.
* **Height 깊이(cm)**: *0.0 - 100.0* Heightmap 세부 정보의 최대 깊이.
* **표준 형식**: *OpenGL, DirectX*\
  서로 다른 표준 맵 포맷 사이를 전환합니다(녹색 채널을 반전합니다).
* **샘플링**: *표준, Sobel*&#x200B;정확도를 결정하는 두 샘플링 모드 사이를 전환합니다.
