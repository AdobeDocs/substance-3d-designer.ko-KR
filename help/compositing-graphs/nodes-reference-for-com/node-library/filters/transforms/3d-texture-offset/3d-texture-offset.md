## 설명

**3D 텍스처 오프셋** 노드는 **입력**&#x200B;에 연결된 *3D 텍스처*&#x200B;에 의해 설명된 개체에 **X**, **Y** 및 **Z** 축의 *오프셋 변환*&#x200B;을 적용합니다.

</td>
</tr>
</table>

## 매개변수

### 입력

* **입력** *회색 음영/색상*\
  3D 개체를 설명하는 *3D 텍스처*&#x200B;입니다.\
  개체는 일반적으로 *단위 큐브*&#x200B;에 설명되어 있습니다.

### 매개변수

* **오프셋** *부동 소수점3*\
  **입력**&#x200B;에 연결된 *3D 텍스처*&#x200B;에 의해 설명된 개체에 적용된 *세계 공간*&#x200B;의 오프셋 양입니다.
