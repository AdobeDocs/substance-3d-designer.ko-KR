## 설명

선택한 측면에서 선택한 축을 기준으로 입력 이미지를 미러링합니다. 대칭 효과를 얻을 수 있는 매우 유용하고 빠른 방법입니다.

## 매개변수

* **모드**: *미러링 축 X, 미러링 축 Y, 미러링* *모퉁이*&#x200B;왼쪽-오른쪽, 위쪽-아래쪽 또는 둘 모두를 미러링하도록 선택합니다.
* **축 X 오프셋**: *0.0 - 1.0*&#x200B;축 X를 선택한 경우에만 오프셋을 정의합니다.
* **축 Y 오프셋**: *0.0 - 1.0*&#x200B;축 Y를 선택한 경우에만 오프셋을 정의합니다.
* **축 X 반전**: *False/True*&#x200B;축 X를 선택한 경우에만 방향을 바꿉니다.
* **축 Y 반전**: *False/True*&#x200B;축 Y를 선택한 경우에만 방향을 전환합니다.
* **모퉁이 유형**: *왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래*&#x200B;모퉁이 유형을 선택한 경우에만 사용하며, 미러링할 모퉁이를 정의합니다.
