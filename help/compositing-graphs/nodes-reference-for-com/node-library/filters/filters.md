# 필터

필터는 다른 잘 알려진 이미징 응용 프로그램에서 가져올 수 있는 방법으로 수정된 &quot;필터링된&quot; 출력을 만들기 위해 입력을 처리하는 노드입니다. [재질 필터](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/material-filters.md)와 큰 차이점은 전체 재질을 나타내지 않는 하나(경우에 따라 더 많은) 입력에서만 작동한다는 것입니다.

필터는 가장 많이 사용되는 주요 범주 중 하나입니다. [Atomic nodes](../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md) 범주 외에 다른 범주는 처음부터 텍스처를 만들 때 유용하지 않습니다. 시간을 내어 각 하위 범주에 대해 알아보십시오.

* [조정](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/adjustments.md)\
  확장된 색상, 톤 및 값 조정.
* [혼합](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blending/blending.md)\
  고급 및 확장 혼합 모드.
* [흐림](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/blurs.md)\
  고급 고품질 흐림 효과
* [채널](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/channels.md)\
  확장된 채널 혼합 노드.
* [효과](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/effects.md)\
  텍스처링 지향 이미지 효과와 &quot;레이어 스타일&quot; 유형 효과
* [표준 맵](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-map.md)\
  표준 맵 중심 작업입니다.
* [타일링](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/tiling.md)\
  노드는 타일링을 수정하고 개선하는 데 초점을 맞췄다.
* [변형](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/transforms/transforms.md)\
  고급(수학) 2D 공간 변환 작업

>[!NOTE]
>
> *사용자 지정* 필터에 대한 간단한 설정을 보여 주는 프로젝트 파일은 이 설명서의 [샘플 Substance 합성 그래프](../../../../compositing-graphs/sample-compositing-graphs/sample-substance-compositing-graphs.md) 섹션에서 사용할 수 있습니다.
