## 설명

지정한 지수로 입력을 출력합니다. [수준](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md)중간점 조정과 비슷하지만 보다 간단한 패키지로 조정됩니다. 정확한 수학적 연산을 수행하려는 경우에도 유용합니다.

중요: [색상] 또는 [회색 음영] 입력 여부에 따라 올바른 버전을 사용해야 합니다.
