## 설명

Heightmap의 주파수를 두 개의 별도 맵으로 나눕니다. 한 맵에는 큰 크기 차이가 있고 다른 맵에는 작은 크기 차이가 있습니다.

## 매개변수

* **부조**: *0.0 - 32.0*&#x200B;변위 출력의 세부 크기를 제어합니다.
