## 설명

색조는 소스 색상을 대상 색상으로 이동합니다.

고급 버전은 [색상 범위 바꾸기](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/replace-color-range/replace-color-range.md) 또는 [색상 일치](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/color-match/color-match.md)를 참조하세요.

## 매개변수

* **소스 색상**: *(색상 값)*색조 전환을 시작할 색상입니다.
* **대상 색상**: *(색상 값)*색조를 방향으로 이동하는 색상입니다.
