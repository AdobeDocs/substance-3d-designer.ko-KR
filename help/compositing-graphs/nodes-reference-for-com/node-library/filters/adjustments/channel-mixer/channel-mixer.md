## 설명

RGB 채널을 혼합하고, 바꾸고, 혼합할 수 있습니다. 패킹을 돌려 이동하고, 회색 음영 변환을 정확하게 하며, 다양한 종류의 채널을 만드는 데 사용할 수 있습니다.

## 매개변수

* **빨강 채널**: *-200.0 -* 200.0\
  입력 RGB 채널을 출력 빨강 채널로 얼마나 많이 입력할지 결정합니다.
* **녹색 채널**: *-200.0 - 200.0*\
  입력 RGB 채널을 출력 녹색 채널로 얼마나 많이 입력할지 결정합니다.
* **파랑 채널**: *-200.0 - 200.0*&#x200B;입력 RGB 채널의 출력 파랑 채널 양을 결정합니다.
* **흑백**: *False/True*&#x200B;흑백으로 출력합니다. 보다 정확한 회색 음영 변환을 지원합니다.
