## 매개변수

|  |  |
|:---|:---|
| <b>최소 범위</b> <i>-2.0 - 0.0</i> | 강조 표시를 시작할 최소 범위입니다. |
| <b>범위 최대</b> <i>1.0 - 3.0</i> | 최대 밝은 영역까지. |
