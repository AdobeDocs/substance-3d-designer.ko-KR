## 설명

몇 가지 사전 설정 변환 모드를 제공하는 고급 빠른 회색 음영 변환 노드입니다.

## 매개변수

* **회색 음영 유형**: *채도 감소, 루마, 평균, 최대, 최소*&#x200B;채도 감소 값은 0으로 설정하고, Luma는 공식적인 광도 가중치를 사용하며, Average는 원자 노드와 동일하며, Max와 Min은 각 채널에 대해 가장 밝은 값을 사용합니다.
