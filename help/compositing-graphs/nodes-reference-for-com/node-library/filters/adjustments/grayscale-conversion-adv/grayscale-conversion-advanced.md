## 매개변수

|  |  |
|:---|:---|
| <b>회색 음영 유형</b> <i>채도 감소, 루마, 평균, 최대, 최소</i> | 채도 감소 는 채도 값을 0으로 설정하고, Luma는 공식적인 광도 가중치를 사용하고, Average는 원자 노드와 같으며, Max와 Min은 각 채널에 대해 가장 밝은 값을 사용합니다. |
