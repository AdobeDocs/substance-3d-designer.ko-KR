## 설명

Min Max는 회색 음영 입력의 가장 밝은 값과 가장 어두운 값을 찾아 [값](../../../../../values-compositing-graphs/values-in-substance-compositing-graphs.md)으로 반환합니다. [자동 수준](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/auto-levels/auto-levels.md)에 대한 보다 세분화되고 수동적인 대안으로서, [수준](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md)노드의 값 입력을 표시하고 최소 최대값의 값을 연결합니다.

이 노드를 수준과 함께 사용하려면 최소한 [노출 매개 변수 드롭다운](../../../../../../compositing-graphs/manage-parameters/exposing-a-parameter/exposing-a-parameter.md)과 [값 입력 탭](../../../../../values-compositing-graphs/values-in-substance-compositing-graphs.md)을 사용하는 방법을 알고 있어야 합니다.
