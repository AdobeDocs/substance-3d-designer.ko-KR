## 설명

범위 한계에 도달하면 주변을 감싸면서 이미지의 전체 범위를 완전히 이동합니다.

[히스토그램 시프트에 대한 Substance 아카데미 비디오를 시청하려면 여기를 클릭하십시오.](https://youtu.be/p9wcmJBFyGA?t=492)

## 매개변수

* **위치**: *0.0 - 1.0*\
  입력을 얼마나 이동할지 지정합니다. 1.0은 전체 회전이며 0.0과 같습니다.
