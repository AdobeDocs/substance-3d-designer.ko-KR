## 설명

전경의 색조 및 색차를 적용하면서 배경의 광도를 유지하는 색상 혼합 모드를 수행합니다.

## 매개변수

### 입력

* **전경**: *색상 입력*
* **배경**: *색상 입력*
* **마스크**: *회색 음영 입력*\
  노드의 효과를 마스킹하는 데 사용되는 마스크 슬롯입니다.

### 매개변수

* **불투명도**: *0.0 - 1.0*\
  전경과 배경 간 불투명도 혼합.
* **Alpha 혼합**: *False/True*\
  전경 및 배경 알파 채널의 혼합을 전환합니다. False로 설정하면 전경의 알파 채널이 무시됩니다.
