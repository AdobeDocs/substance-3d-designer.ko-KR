# 흐림 효과

[흐림 효과] 범주는 [표준, 원자 상자 흐림 효과 노드](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blur/blur.md)에서 확장됩니다. 여기에는 여러 용도로 사용되는 고급 고품질 흐림 효과가 포함됩니다.

모든 라이브러리 흐림 효과 노드는 회색 음영과 색상 버전으로 제공됩니다. 입력에 적합한 버전을 사용해 보세요!
