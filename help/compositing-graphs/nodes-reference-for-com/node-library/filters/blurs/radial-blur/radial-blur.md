## 설명

입력에 회전하는 동작 유형의 흐림 효과를 생성합니다.

## 매개변수

* **샘플**: *1 - 128*&#x200B;흐림 효과의 품질을 설정합니다.
* **각도**: *0.0 - 0.5*&#x200B;효과의 &quot;회전&quot; 양을 설정합니다.
* **가운데 위치**:\
  효과의 중심점을 설정합니다.
