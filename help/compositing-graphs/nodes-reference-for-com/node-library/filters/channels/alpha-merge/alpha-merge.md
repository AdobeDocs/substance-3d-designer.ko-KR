## 설명

알파 채널이 없는 입력에 알파 채널을 추가합니다. [RGBA 병합](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/rgba-merge/rgba-merge.md)과 혼동하지 마세요. 이 노드는 훨씬 간단하고 알파만 추가합니다!

무엇인가를 마스킹하고 싶을 때 또는 결과에 알파가 필요할 때 사용할 수 있는 간단하지만 편리한 노드.

## 매개변수

### 입력

* **RGB**: *색상 입력*\
  알파 없는 색상 이미지
* **A**: *회색 음영 입력*\
  결과 알파로 사용할 회색 음영 이미지입니다.

*매개 변수가 없습니다.*
