## 설명

입력 이미지를 빨강, 녹색, 파랑 및 알파 채널로 분할합니다. 이미지를 효과적으로 &quot;압축 해제&quot;합니다.

압축된 채널을 별도로 분석하고 사용하는 데 유용합니다. 적용된 위치 맵 또는 적용된 월드 스페이스 표준 맵을 Substance Painter 효과에 사용할 때 예를 들어 X, Y 또는 Z 구성 요소를 하나로 합성할 수 있습니다.
