## 설명

알파 블렌드 가장자리의 RGB에서 미리 곱하기 색상을 제거합니다. 배경색을 효과적으로 &quot;사전 곱하기&quot;하지만 프로세스에서 알파 채널을 제거하지는 않습니다.

이렇게 하면 알파 채널이 있는 이미지의 가장자리 주변에서 가끔 나타나는 언저리 효과를 제거합니다.
