# 마스크 작성기

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>내부:</b> 메시 기반 생성기 > 마스크 생성기

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 설명

베이킹된 맵 및 사용자 설정을 기반으로 흑백 마스크를 생성합니다. 이는 Painter 마스크 빌더의 Designer 버전과 거의 비슷합니다.

이 도구는 베이킹된 맵, 사용자 매개 변수, 그런지 패턴 및 맵을 기반으로 모든 것을 포괄하는 마스크 빌더로 사용되는 복잡한 도구입니다. 이것은 주로 주름 Dirt 및 에지 마모에 혼합하기 위한 매우 진보된 완전 제어 노드로 의도된다. 이 노드는 다른 모든 마스크 생성기를 모방할 수 있을 만큼 강력합니다.

베이크는 명시적으로 필요하지 않지만 공급량이 많을수록 이 노드가 더 많은 작업을 수행할 수 있습니다.

## 입력

|  |  |
|:---|:---|
| <b>주변 오클루전</b> <i>회색 음영 입력</i> |  |
| <b>곡률</b> <i>회색 음영 입력</i> |  |
| <b>월드 스페이스 표준</b> <i>색상 입력</i> |  |
| <b>그런지 입력</b> <i>회색 음영 입력</i> |  |
| <b>그런지 입력 2</b> <i>회색 음영 입력</i> |  |
| <b>산란 입력</b> <i>회색 음영 입력</i> | 사용자 정의 산란 스탬프, 산란 매개 변수를 사용하는 데 필요. |
| <b>마스크(선택 사항)</b> <i>회색 음영 입력</i> | 노드의 효과를 마스킹하는 데 사용되는 마스크 슬롯입니다. |
| <b>위치</b> <i>색상 입력</i> | [삼각 평면] 및 [위 아래] 효과에 사용됩니다. |

## 매개변수

|  |  |
|:---|:---|
| <b>수준</b> <i>0.0 - 1.0</i> | 효과의 전체 수준을 점진적으로 표시합니다. |
| <b>대비</b> <i>0.0 - 1.0</i> | 결과의 대비를 조정합니다. |
| <b>반전</b> <i>거짓/참</i> | 결과를 반전합니다. 만들고 있는 마스크와 반대되는 결과를 얻을 때 유용합니다. |
| <b>Triplanar 사용</b> <i>거짓/참</i> | 그런지 맵으로 이음새를 방지하면서 삼평면 투영을 활성화합니다. |
| <b>삼평면 혼합 대비</b> <i>0.0 - 1.0</i> | 삼면체 블렌딩의 대비를 설정합니다. |
| <b>그런지</b> <i>0.0 - 1.0</i> | 전역으로 혼합할 그런지 양을 설정합니다. |
| <b>그런지</b> |  |
| <b>크기 조절</b> <i>0 - 10</i> | 전역 그런지의 비율을 설정합니다. |
| <b>사용자 지정 그런지 사용</b> <i>거짓/참</i> | 사용자 지정 그런지 입력을 활성화합니다. |
| <b>보조 사용자 지정 그런지</b> <i>0.0 - 1.0</i> | 두 번째 사용자 지정 그런지 입력을 활성화합니다. |
| <b>반전</b> <i>거짓/참</i> | 그런지 맵을 반전합니다. |
| <b>AO</b> <i>-1.0 - 1.0</i> | 가려진 AO 영역에서 효과가 나타날 정도를 설정합니다. 아래 그룹을 사용하여 조정할 수 있습니다. |
| <b>AO</b> |  |
| <b>범위</b> <i>0.0 - 1.0</i> | Dirt 모양에 대한 임계값 또는 범위를 설정합니다. |
| <b>대비</b> <i>0.0 - 1.0</i> | AO 효과의 대비를 조정합니다. |
| <b>소음</b> <i>0.0 - 1.0</i> | AO 효과에 혼합할 노이즈/그런지 양을 설정합니다. |
| <b>노이즈 비율</b> <i>0 - 10</i> | AO 노이즈/그런지의 비율을 설정합니다. |
| <b>노이즈 유형</b> <i>스팟, 구름, 습기, 백색 노이즈</i> | 4가지 다른 유형의 AO 노이즈 사이를 전환합니다. |
| <b>반전</b> <i>거짓/참</i> | AO 맵의 해석을 반전합니다. 노이즈는 어두운 영역이 아니라 밝은 AO 영역에 나타납니다. |
| <b>곡률</b> <i>0.0 - 1.0</i> | 곡률 모서리에 표시할 효과를 설정합니다. 볼록과 오목이 모두 될 수 있습니다. 아래 그룹과 함께 이 부분을 조정합니다. |
| <b>곡률</b> |  |
| <b>볼록 범위</b> <i>-1.0 - 1.0</i> | 볼록(밝은) 곡률 가장자리에 표시할 효과의 양을 설정합니다. |
| <b>볼록 대비</b> <i>0.0 - 1.0</i> | [볼록] 효과의 대비를 설정합니다. |
| <b>볼록 반전</b> <i>거짓/참</i> | [볼록] 가장자리의 해석을 반전합니다. |
| <b>오목 범위</b> <i>-1.0 - 1.0</i> | 오목(어두운) 곡률 가장자리에 표시할 효과의 양을 설정합니다. |
| <b>오목 대비</b> <i>0.0 - 1.0</i> | 오목 범위의 대비를 설정합니다. |
| <b>오목 반전</b> <i>거짓/참</i> | 오목한 가장자리의 해석을 반전시킵니다. |
| <b>Smoothness</b> <i>0.0 - 16.0</i> | 곡률 가장자리에 적용할 흐림 및 매끄러움의 양입니다. |
| <b>수준 향상</b> <i>0.0 - 1.0</i> | 효과가 충분히 보이지 않으면 추가 부스터. |
| <b>소음</b> <i>0.0 - 1.0</i> | [곡률] 효과에 대한 노이즈/그런지 영향을 설정합니다. |
| <b>노이즈 비율</b> <i>0 - 10</i> | 노이즈 크기를 설정합니다. |
| <b>노이즈 유형</b> <i>스팟, 구름, 습기, 백색 노이즈</i> | 4가지 노이즈 유형 중에서 선택합니다. |
| <b>위/아래 그레이디언트</b> <i>-1.0 - 1.0</i> | [위치] 맵을 기반으로 위에서 아래로 그레이디언트를 사용하여 혼합을 올리거나 마스크합니다. 양수 값을 지정하면 더 밝아지고, 음수 값을 지정하면 기존 효과가 마스킹됩니다. |
| <b>그레이디언트</b> |  |
| <b>범위</b> <i>0.0 - 1.0</i> | 그레이디언트의 위치를 설정합니다. |
| <b>대비</b> <i>0.0 - 1.0</i> | 그레이디언트의 대비를 조정합니다. |
| <b>반전</b> <i>거짓/참</i> | 그레이디언트를 반전시킵니다. 하단과 상단을 효과적으로 교체합니다. |
| <b>월드 스페이스 표준</b> <i>0.0 - 1.0</i> | [위/아래 그레이디언트]와 유사하지만, 위치 맵과 6개 방향으로 배치하면 마치 가짜 조명과 같습니다. 양수 값을 입력하면 밝아지고, 음수 값을 입력하면 어두워집니다. |
| <b>월드 스페이스 표준</b> |  |
| <b>상위 강도</b> <i>-1.0 - 1.0</i> |  |
| <b>아래쪽 강도</b> <i>-1.0 - 1.0</i> |  |
| <b>정면 강도</b> <i>-1.0 - 1.0</i> |  |
| <b>뒤로 강도</b> <i>-1.0 - 1.0</i> |  |
| <b>오른쪽 강도</b> <i>-1.0 - 1.0</i> |  |
| <b>왼쪽 강도</b> <i>-1.0 - 1.0</i> |  |
| <b>Scratches</b> <i>-1.0 - 1.0</i> | 혼합이 흰색 영역을 긁습니다. |
| <b>Scratches</b> |  |
| <b>금액</b> <i>0 - 4096</i> | 전체 스크래치 양을 설정합니다. |
| <b>크기 조절</b> <i>0.0 - 1.0</i> | 개별 스크래치 크기를 설정합니다. |
| <b>산란</b> <i>-1.0 - 1.0</i> | 흰색 영역 내에 사용자 정의 스탬프를 산란으로 지정합니다. |
| <b>산란</b> |  |
| <b>크기 조절</b> <i>0 - 50</i> | 효과의 전체 비율입니다. |
| <b>밀도</b> <i>0.0 - 1.0</i> | 분산 밀도 컨트롤, 표시되어야 하는 수입니다. |
| <b>크기</b> <i>0.0 - 4.0</i> | 흩어진 스탬프의 크기입니다. |
| <b>크기 변형</b> <i>0.0 - 1.0</i> | 스탬프 크기 내의 변형. |
| <b>불투명도 변형</b> <i>0.0 - 1.0</i> | 스탬프 불투명도 내의 변형. |
