## 설명

이것은 &quot;컴팩트 재질 모드&quot;와 함께 사용하기 위해 단일 그룹에 &quot;팩&quot;된 메시 데이터를 제공하는 매우 간단한 노드입니다.

이 노드는 대부분 [재질 메시 데이터 블렌더](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/utilities-mesh-based-gen/material-mesh-data-ble/material-mesh-data-blender.md)와 같이 갤러리의 특정 노드에서 많은 구운 입력을 사용하여 더 쉽게 작업할 수 있도록 하는 도우미입니다. 이 도구를 사용하면 모든 것을 수동으로 연결하지 않아도 됩니다.

## 매개변수

### 매개변수

맵 입력을 활성화하여 압축된 결과로 출력하려면 해당 입력을 전환합니다.

* **주변 오클루전**: *False/True*
* **UV 마스크**: *False/True*
* **곡률**: *거짓/참*
* **Height**: *False/True*
* **위치(회색 음영)**: *False/True*
* **Thickness**: *False/True*
* **표준**: *False/True*
* **위치(RGB)**: *False/True*
* **색상 ID**: *False/True*
* **세계 우주 방향**: *False/True*
* **월드 스페이스 표준**: *False/True*
