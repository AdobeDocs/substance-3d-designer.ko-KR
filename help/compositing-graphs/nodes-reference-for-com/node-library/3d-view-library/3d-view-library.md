# 3D 보기(라이브러리)

[3D 보기] 범주에는 Substance 3D Designer의 3D 보기에서 사용된 구형 투영 HDRI와 관련된 노드 또는 Substance 3D Painter과 같은 다른 애플리케이션으로 내보내기 위한 노드만 포함됩니다.

두 가지 하위 범주가 있습니다.

* **HDRI 환경**: 사용 가능한 설명서가 없습니다. 이 설명서는 3D 보기에 표시할 수 있는 이미지이며 추가 매개 변수가 없습니다.
* **HDRI 도구**: 구형 HDRI 이미지를 만들고 편집하기 위한 도구 노드입니다. SD 2019.2에 도입되었습니다.
