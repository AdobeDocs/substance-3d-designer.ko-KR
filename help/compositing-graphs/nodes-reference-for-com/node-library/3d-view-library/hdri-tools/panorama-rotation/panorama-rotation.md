## 설명

* **회전**: *0.0 - 1.0*
* **방향 각도**: *0.0 - 1.0*
* **극을 중심으로 사전 회전**: *-1.0 - 1.0*
* **기둥을 중심으로 회전 게시**: *0.0 - 1.0*
