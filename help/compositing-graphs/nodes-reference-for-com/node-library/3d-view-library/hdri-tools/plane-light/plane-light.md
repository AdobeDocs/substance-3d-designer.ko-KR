## 설명

구형으로 투영된 평면 모양을 생성합니다. 입력 매개변수를 사용하여 3d에서 평면을 배치하고 방향을 지정할 수 있습니다.

단순한 원점으로부터의 거리 투영 이외의 더 고급 배치 옵션이 있고 [선 조명](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/3d-view-library/hdri-tools/line-light/line-light.md)과 같이 더 많은 패턴 및 마스크를 적용할 수 있다는 점에서 단순한 [모양 조명](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/3d-view-library/hdri-tools/shape-light/shape-light.md)과 다릅니다.

## 입력

* **배경 이미지 입력**: *색상 입력*\
  생성된 빛을 구성할 선택적 배경입니다.
* **모양 이미지 입력**: *색상 입력*\
  라인 조명에 매핑할 선택적 이미지입니다. [모양 색상 모드]가 [이미지 입력]으로 설정된 경우에만 사용됩니다.
* **패턴 이미지 입력**: *회색 음영 입력*\
  &quot;Pattern&quot; 매개 변수를 &quot;Image Input&quot;으로 설정한 경우 사용되는 사용자 정의 패턴 이미지입니다.

## 매개변수

* **위치 모드**: *지상/천장, 원점으로부터의 거리, 세계 위치*\
  세 가지 배치 모드 중에서 선택합니다. 2D 보기에서 지면/천장 및 원점으로부터의 거리 지원 조작, World 위치는 속성을 통해서만 변경할 수 있지만 보다 정확한 배치를 지원합니다.
* **지표 표시**: *False/True*\
  디버그 그라운드 그리드를 그릴 수 있도록 하는 도우미 함수입니다. 공간에서 선의 위치를 추정하는 데 도움이 됩니다.
* **위치 좌표**
  * **위쪽 벡터**: *위쪽 Z, 위쪽 Y*\
    세계 위치 모드에서만 좌표계의 방향을 결정합니다.
  * **평면 UV 위치**:\
    바닥 / 천장 및 원점으로부터의 거리가 있어야합니다. UV 공간에서 평면 위치를 설정합니다.
  * **평면 세계 위치**: *-2.0 - 2.0*\
    월드 포지션 모드만 사용 가능. 평면 위치 세계 공간을 설정합니다. 지원되는 2D 보기 상호 작용이 없습니다.
  * **평면 절대 Height**: *0.0 - 1.0*\
    지표/천장 위치 모드에서만 천장으로부터 절대 Height을 설정합니다. 위치를 더 잘 추정하려면 [지표 격자 표시]를 사용합니다.
  * **원점으로부터의 거리**: *0.0 - 1.0*\
    원점으로부터의 거리 위치 모드에서만 가능합니다. 두 점의 파노라마 중심으로부터의 거리를 설정합니다.
* **모양 색상 모드**: *RGB, 온도(켈빈), 이미지 입력*\
  모양 색상을 설정하는 데 사용할 방법을 선택합니다. 이미지 입력(Image Input)은 두 번째 입력 슬롯을 사용할 수 있게 합니다.
* **색상**: *(색상 값)*\
  [모양 색상 모드]가 [RGB]로 설정된 경우에만 가능합니다. 모양의 색상을 선택합니다.
* **온도**: *800.0 - 20000.0*\
  [모양 색상 모드]가 [온도]로 설정된 경우에만 가능합니다. 모양 색상의 켈빈 값을 설정합니다.
* **모양 이미지 UV 모드**: *늘이기, 중간 늘이기, 반복 + 간격*\
  [모양 색상 모드]가 [이미지 입력]으로 설정된 경우에만 가능합니다. 선 모양에 이미지가 적용되는 방식을 설정하고 UV 반복 동작을 결정합니다.
* **모양 이미지 반복 간격**: *0.0 - 1.0*\
  [모양 색상 모드]가 [이미지 입력]으로 설정되고 [UV 모드]가 [반복 + 간격]으로 설정된 경우에만 가능합니다. 이미지가 선을 따라 반복될 때의 간격 값을 설정합니다.
* **모양 이미지 감마**: *sRGB, 선형*\
  [모양 색상 모드]가 [이미지 입력]으로 설정된 경우에만 가능합니다. 모양 이미지 입력을 해석하는 방법을 결정합니다.
* **노출(EV)**: *0.0 - 10.0*\
  생성된 모양에 대한 노출 값 설정, 배경 이미지 노출 값과 이상적인 일치.
* **평면 크기**: *0.0 - 1.0*\
  평면 모양의 비율을 균일하게 설정합니다.
* **평면 크기**: *0.0 - 1.0*\
  평면 모양의 크기를 균일하지 않게 설정합니다.
* **평면 회전**: *0.0 - 1.0*\
  중심 축을 따라 평면을 회전합니다.
* **패턴**: *부드러운 사각형, 날카로운 사각형, 원뿔, 반구, 이미지 입력*\
  사용할 패턴 모양을 선택합니다.
* **패턴 경도**: *0.0 - 1.0*\
  패턴의 경도/대비를 설정합니다.
* **패턴 UV 모드**: *늘이기, 중간 늘이기*\
  [모양] 이미지 위에 적용된 보조 패턴 마스크를 사용하는 방법을 설정합니다.
* **지표 클리핑 사용**: *False/True*\
  [평면]이 지표 평면으로 클리핑될 수 있거나 지표 평면 아래로 이동할 때 계속 표시되는 경우 이 옵션을 활성화합니다. 이 값을 더 잘 추정하려면 [지표 격자 표시]를 사용합니다.
* **지표 Height**: *-2.0 - 0.0*\
  클리핑의 지표 Height을 조정합니다.
* **배경 입력 사용**: *False/True*\
  선택적 배경 이미지 사용을 전환합니다. 합성 이미지에서 배경 상단에 조명이 생성되었습니다.
* **배경색**: *(색상 값)*\
  [배경 입력]을 사용하지 않는 경우에는 여기에서 단색 배경 값을 설정합니다.
* **배경 감마**: *sRGB, 선형*&#x200B;배경 입력을 사용하는 경우 배경 입력을 해석하는 방법을 설정하십시오.
