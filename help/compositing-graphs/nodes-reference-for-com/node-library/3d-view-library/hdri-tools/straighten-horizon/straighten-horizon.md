## 설명

수평선이 직선이 아닌 HDRI의 경우 이 노드를 사용하면 쉽고 사용자 친화적으로 이를 수정할 수 있습니다.

## 매개변수

|  |  |
|:---|:---|
| <b>수평선 교정 사용</b> <i>거짓/참</i> | 효과를 활성화 및 비활성화합니다. 전환을 통해 보정 전 비교할 수 있으며, 정확한 점을 찾을 수 있습니다. |
| <b>수평점 #1 위치</b> | 첫 번째 포인트에는 2D 보기 핸들이 있습니다. |
| <b>수평점 #2 위치</b> | 두 번째 포인트에는 2D 뷰 핸들이 있습니다. |
| <b>수평 회전</b> <i>0.0 - 1.0</i> | 중심 축을 중심으로 추가 회전. |
