## 설명

여러 사진 노출을 병합하여 High Dynamic Range 이미지를 만듭니다. 첫 번째 입력은 가장 노출이 부족한 이미지입니다.

## 입력

* **입력 1-**** 16**: *색상 입력*입력 이미지. 사용 가능한 양은 매개변수에 따라 다릅니다.

## 매개변수

* **입력**: *2 - 16*\
  사용 가능한 입력 양을 설정합니다.
* **노출 델타(EV)**: *0.0 - 4.0*\
  이미지 간 해석을 위해 노출의 차이를 설정합니다.
* **흰 점**: *0.0 - 13.0*&#x200B;최종 결과에서 일부 조정을 수행하도록 흰 점을 설정합니다.
