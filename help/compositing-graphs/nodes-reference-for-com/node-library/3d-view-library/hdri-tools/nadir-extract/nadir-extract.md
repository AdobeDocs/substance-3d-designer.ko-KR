## 설명

구형으로 매핑된 입력 이미지의 중앙 접지점(nadir)을 추출합니다. 카메라 또는 삼각대를 마스크 아웃하여 한 이미지의 아래를 다른 이미지로 전송하는 데 사용할 수 있습니다.

## 매개변수

* **비율**: *0.0 - 10.0*\
  지표 지점의 &quot;확대/축소 레벨&quot; 설정
* **회전**: *0.0 - 1.0*\
  중심 축을 중심으로 회전합니다.
* **출력 감마**: *sRGB, 선형*&#x200B;출력 감마.
