## 설명

구형으로 매핑된 입력 이미지의 중앙 접지점(nadir)을 추출합니다. 카메라 또는 삼각대를 마스크 아웃하여 한 이미지의 아래를 다른 이미지로 전송하는 데 사용할 수 있습니다.

</td>

<a name="parameters"></a>

## 매개변수

|  |  |
|:---|:---|
| <b>크기 조절</b> <i>0.0 - 10.0</i> | 지표 지점의 &quot;확대/축소 레벨&quot; 설정 |
| <b>회전</b> <i>0.0 - 1.0</i> | 중심 축을 중심으로 회전합니다. |
| <b>출력 감마</b> <i>sRGB, 선형</i> | 출력 감마. |
