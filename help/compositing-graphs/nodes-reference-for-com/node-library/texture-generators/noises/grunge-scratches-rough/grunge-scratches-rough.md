|  |  |
|:---|:---|
| <b>균형</b> <i>부동</i> | 어두운 값과 밝은 값 간의 균형을 조정합니다. |
| <b>대비</b> <i>부동</i> | 이미지의 대비를 조정합니다. |
| <b>반전</b> <i>부울</i> | `1-x` 작업을 사용하여 이미지의 출력을 반전합니다. |
| <b>비정사각형 확장</b> <i>부울</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다. |
| <b>고급</b> |  |
| <b>스크래치 양</b> <i>부동</i> | 표면의 스크래치 양을 조정합니다. |
| <b>스크래치 타일링</b> <i>정수</i> | 스크래치에 적용되는 타일링의 양을 조정합니다. |
| <b>스크래치 흐림 효과</b> <i>부동</i> | 스크래치의 흐림 효과를 조정합니다. |
| <b>스크래치 너비</b> <i>부동</i> | 스크래치 폭을 조정합니다. |
| <b>스크래치 길이</b> <i>부동</i> | 스크래치 길이를 조정합니다. |
| <b>스크래치 마스크</b> <i>부동</i> | 스크래치 일부에 적용된 마스크 강도를 조정합니다. |
| <b>스크래치 더러움</b> <i>부동</i> | 스크래치의 얼룩을 조정하여 날카로움과 연속성을 떨어뜨립니다. |
| <b>이중 스크래치</b> <i>부동</i> | 약간의 뒤틀기 효과를 사용하여 각 스크래치 옆에 적용된 두 번째 스크래치 불투명도를 조정합니다. |
| <b>스크래치 스팟 강도</b> <i>부동</i> | 스크래치 옆에 적용된 손상된 스팟의 강도를 조정합니다. |

| <b>Dust 강도</b> <i>부동</i> | Dust 오버레이의 강도를 조정합니다. |

| <b>선명 효과 강도</b> <i>부동</i> | 전체 선명하게 하기 효과의 강도를 조정합니다. |
