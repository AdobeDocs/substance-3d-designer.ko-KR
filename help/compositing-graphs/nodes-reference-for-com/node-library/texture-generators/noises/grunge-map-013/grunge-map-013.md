## 설명

이렇게 하면 복잡하고 결합된 노이즈맵이 생성됩니다. 이 방법은 세부 절차로서 매우 유용할 수 있지만 성능이 매우 집중되어 생성이 느리다는 점을 명심하십시오.

## 매개변수

* **균형**: *0.0 - 1.0*\
  명도 조정처럼 결과의 균형을 검정이나 흰색 사이에서 이동합니다.
* **대비**: *0.0 - 1.0*\
  결과의 대비를 조정합니다.
* **반전**: *False/True*\
  결과를 반전합니다.
* **브러시 패턴**: *0.0 - 1.0*\
  브러시 알파로 사용할 경우에 사용하도록 가장자리 주위에 마스크를 추가합니다.
* **비정사각형 확장**: *False/True*\
  제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다.
