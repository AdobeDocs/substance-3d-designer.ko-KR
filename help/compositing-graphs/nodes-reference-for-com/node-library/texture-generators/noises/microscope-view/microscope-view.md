## 설명

이것은 현미경으로 박테리아나 유기체처럼 보이는 뒤틀린 소음을 발생시킨다.

## 매개변수

* **비율**: *0 - 10*\
  효과의 전체 배율을 설정합니다.
* **뒤틀기 강도**: *0.0 - 1.0*\
  뒤틀기 효과의 강도를 설정합니다. -1을 두 번 클릭하여 입력하면 음수로도 갈 수 있습니다.
* **장애**: *0.0 - 1.0*\
  작은 변화를 가져오기 위해 노이즈를 위상 이동
* **비정사각형 확장**: *False/True*\
  제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다.
