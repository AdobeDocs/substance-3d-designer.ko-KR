## 매개변수

|  |  |
|:---|:---|
| <b>균형</b> <i>부동</i> | 어두운 값과 밝은 값 간의 균형을 조정합니다. |
| <b>대비</b> <i>부동</i> | 이미지의 대비를 조정합니다. |
| <b>반전</b> <i>부울</i> | `1-x` 작업을 사용하여 이미지의 출력을 반전합니다. |
| <b>비정사각형 확장</b> <i>부울</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다. |
| <b>고급</b> |  |
| <b>기본 그런지 대비</b> <i>부동</i> | 녹의 기준으로 사용되는 그런지 텍스처의 대비를 조정합니다. |
| <b>기본 뒤틀기 강도</b> <i>부동</i> | 녹의 기준으로 사용되는 그런지 맵에 적용된 뒤틀기 효과의 강도를 조정합니다. |
| <b>줄무늬 강도</b> <i>부동</i> | 기본 그런지 텍스처에 겹쳐진 더 밝은 줄무늬와 스팟의 강도를 조정합니다. |
| <b>노이즈 강도</b> <i>부동</i> | 기본 그런지 텍스처에 적용된 노이즈의 강도를 조정합니다. |
| <b>선명 효과 강도</b> <i>부동</i> | 전체 선명하게 하기 효과의 강도를 조정합니다. |
