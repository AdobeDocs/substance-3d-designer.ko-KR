## 설명

[Substance 3D Designer](https://www.adobe.com/kr/products/substance3d-designer.html)의 **그런지 흔들림** 노드는 표면에 흩어진 흔들림과 유사한 그런지 맵을 생성합니다.

## 매개변수

|  |  |
|:---|:---|
| <b>균형</b> <i>부동</i> | 어두운 값과 밝은 값 간의 균형을 조정합니다. |
| <b>대비</b> <i>부동</i> | 이미지의 대비를 조정합니다. |
| <b>반전</b> <i>부울</i> | `1-x` 작업을 사용하여 이미지의 출력을 반전합니다. |
| <b>비정사각형 확장</b> <i>부울</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다. |
| <b>고급</b> |  |
| <b>스크래치 스팟 양</b> <i>부동</i> | 흔들림을 생성하는 데 사용되는 스크래치 스팟 효과의 양과 *적용 범위*&#x200B;입니다. |
| <b>스크래치 스팟 타일링</b> <i>정수</i> | 흔들림을 만드는 데 사용되는 긁힌 스팟 효과의 타일링 양입니다. |
| <b>Dust 강도</b> <i>부동</i> | 표면의 Dust 오버레이 강도입니다. |
| <b>선명 효과 강도</b> <i>부동</i> | 전체 선명하게 하기 효과의 강도입니다. |
