## 매개변수

|  |  |
|:---|:---|
| <b>크기 조절</b> <i>1 - 8</i> | 효과의 전체 배율을 설정합니다. |
| <b>파도 눈금</b> <i>0.0 - 1.0</i> | 파동의 크기를 수정합니다. 값이 클수록 반복이 적습니다. |
| <b>물결 회전</b> <i>0.0 - 1.0</i> | 파도를 더 비틉니다. 결과가 극단적일 수 있으므로 이 값은 낮게 유지되어야 합니다. |
| <b>비정사각형 확장</b> <i>거짓/참</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다. |
