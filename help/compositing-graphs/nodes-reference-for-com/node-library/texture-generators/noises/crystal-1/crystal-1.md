## 매개변수

|  |  |
|:---|:---|
| <b>크기 조절</b> <i>1 - 256</i> | 효과의 전체 배율을 설정합니다. |
| <b>장애</b> <i>0.0 - 1.0</i> | 작은 변화를 가져오기 위해 노이즈를 위상 이동합니다. |
| <b>비정사각형 확장</b> <i>거짓/참</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다. |
