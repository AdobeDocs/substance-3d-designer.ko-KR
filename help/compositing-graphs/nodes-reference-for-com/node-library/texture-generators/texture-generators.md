# 텍스처 생성기

텍스처 생성기는 입력이 필요하지 않은 노드입니다. 완전히 처음부터 이미지를 생성합니다. &#39;질감 생성기들&#39;을 &#39;절차&#39;의 다른 말로 생각할 수 있다.

두 범주로 나뉩니다.

* [잡음](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/noises.md)\
  노이즈는 절차적 그래픽이며, 임의의 모양과 픽셀로, 잘 알려진 펄린 및 구름 노이즈와 같습니다.
* [패턴](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/patterns.md)\
  패턴은 대부분 사람이 만든 것처럼 보이는 모양이며 임의 설정을 위한 많은 추가 컨트롤이 있습니다.
