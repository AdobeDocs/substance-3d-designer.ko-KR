## 설명

노드에서 제공한 추가 데이터를 사용하여 [모양 스플래터 v2](../shape-splatter-v2/shape-splatter-v2.md) 노드를 사용하여 생성 및 흩어진 모양에 회색 음영 이미지를 매핑합니다.<br><br>이미지는 별도의 패턴 입력으로 제공되거나 그리드 아틀라스에 압축되어 있으며 UV 매핑, 삼면형 투영 또는 사용자 지정 매핑을 사용하여 모양에 적용할 수 있습니다.<br><br>모양은 색조가 적용될 수 있으며 모양마다 광도가 균일하게 또는 무작위로 조정됩니다.

[모양 스플래터 v2 매퍼 색상](../shape-splatter-v2-mapper-color/shape-splatter-v2-mapper-color.md)도 참조하세요.

## 매개변수

|                                            |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:-------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>투영 모드</b> *정수* | 입력 이미지를 모양에 투영하는 방법:<br><br>- <b>스플래터 UV에서:</b> [모양 스플래터 v2](../shape-splatter-v2/shape-splatter-v2.md) 노드에서 제공하는 UV를 사용합니다.<br>- <b>삼면형:</b> 삼면형 투영을 사용하여 모양의 로컬 XYZ 축에 이미지를 매핑합니다.<br>- <b>사용자 지정 함수:</b> 함수 그래프를 작성하여 모양에 이미지 매핑을 정의합니다. |
| <b>사용자 지정 함수</b> *부동* | 모양의 픽셀당 광도를 플로트로 지정합니다.<br><br>다음 변수를 사용할 수 있습니다.<br>- <code>shape.position.os</code> (Float3) 개체 공간에서 모양 표면의 위치입니다.<br>- <code>shape.position.ws</code> (Float3) 월드 공간에서 모양 표면의 위치*.<br>- <code>shape.normal.os</code> (Float3) 개체 공간에서 모양 표면의 표준입니다.<br> - <code>shape.normal.ws</code> (Float3) world space*.<br>- <code>shape.id에서 모양 표면의 표준</code> (부동) 모양의 고유 식별자입니다.<br>- <code>material.id</code> (Float) [모양 스플래터 v2](../shape-splatter-v2/shape-splatter-v2.md) 노드에 의해 정의된 모양 표면의 재질 ID.<br><br>*: 모양의 월드 공간은 피벗을 중심으로 하며 모양의 Height을 고려하지 않습니다. 즉, 개체 공간과의 유일한 차이는 방향입니다.<br><br>[모양 스플래터 v2 매퍼 회색 음영](shape-splatter-v2-mapper-grayscale.md) 노드의 입력을 샘플링해야 하는 경우 다음 [샘플 회색 음영](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md) 노드 입력 슬롯을 사용할 수 있습니다.<br>- 0: 그리드 아틀라스<br>- 1-8: 패턴 입력 1-8 |
| <b>대비 혼합</b> *부동* | 평면 투영 간의 변환의 선명도입니다. 여기서 1은 페이드 그레이디언트가 없음을 의미합니다. |
| <b>이미지 투영</b> *정수* | 평면 투영에 걸쳐 분포된 <b>패턴 입력 #</b> 이미지의 양으로 삼각 평면 매핑에 기여합니다.<br><br>모양의 모든 면을 덮을 수 있도록 각 축에서 앞면(+) 및 뒷면(-) 평면 투영을 수행하여 총 6개의 투영을 수행합니다.<br><br>- <b>1 이미지:</b> 패턴 입력 1은 모든 평면 투영에 사용됩니다.<br>- <b>3 이미지:</b> 각 축의 +/- 투영에는 별도의 패턴 입력이 사용됩니다.<br>- <b>6 이미지:</b> 각 투영은 별도의 패턴 입력을 사용합니다.<br>- <b>재료 ID당 이미지:</b> 재료 ID당 별도의 패턴 입력을 사용합니다. 여기서 각 이미지는 모든 평면 투영에 사용됩니다. |
