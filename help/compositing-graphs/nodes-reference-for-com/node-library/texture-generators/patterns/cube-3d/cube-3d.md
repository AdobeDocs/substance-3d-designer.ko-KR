## 설명

화면 깊이 역할도 하는 음영을 사용하여 회색 음영 3D 큐브를 렌더링합니다. 이렇게 해서 만들어진 정육면체는 고정밀 비트 깊이로 사용할 때 매우 선명하고 선명한 가장자리를 갖습니다. 매우 흥미롭고 유용합니다!

</td>

<a name="parameters"></a>

## 매개변수

|  |  |
|:---|:---|
| <b>방향 오프셋</b> | 큐브의 3D 유사 X 및 Y 회전을 허용합니다. 2D 미리 보기에서 작은 점을 조작하여 수행할 수도 있습니다(아래 예제에 표시됨). |
| <b>크기</b> <i>0.0 - 1.0</i> | 큐브의 균일하지 않은 크기 조정을 허용합니다. |
| <b>크기 조절</b> <i>0.0 - 1.0</i> | 전체 육면체의 비율을 균일하게 조정합니다. |
| <b>비정사각형 확장</b> <i>거짓/참</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다. |
