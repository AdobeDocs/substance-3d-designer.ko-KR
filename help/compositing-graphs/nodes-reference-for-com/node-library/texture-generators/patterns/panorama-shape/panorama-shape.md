## 설명

프로시저 &quot;Studio&quot; 유형의 파노라마 맵을 생성하는 데 유용한 노드입니다. 스포트라이트 이미지를 배치 및 수정하고 해당 HDR 속성을 설정할 수 있습니다. 여러 모양에 대해 함께 체인으로 연결할 수 있습니다.

</td>

<a name="parameters"></a>

## 매개변수

|  |  |
|:---|:---|
| <b>모양 매트릭스</b> | 캔버스와 직접 상호 작용하여 수정할 수 있는 결과물을 이동하거나 변환합니다. |
| <b>모양</b> <i>정사각형, 디스크</i> | 모양 유형을 설정합니다. |
| <b>모양 색상</b> <i>(색상 값)</i> | 모양 색상을 설정합니다. |
| <b>모양 강도</b> <i>0.0 - 100.0</i> | 모양의 HDR 강도를 설정합니다. |
| <b>부드러운 테두리 모양</b> <i>0.0 - 1.0</i> | 모양의 테두리 부드러움을 변경합니다. |
| <b>핫스팟 강도</b> <i>0.0 - 100.0</i> | 모양 핫스폿의 HDR 강도를 설정합니다. |
| <b>핫스팟 크기</b> <i>0.0 - 1.0</i> | 모양 내에서 핫스폿의 크기를 변경합니다. |
| <b>핫스폿 밝기 감소</b> <i>0.0 - 1.0</i> | 핫스폿의 밝기 감소, 가장자리 혼합을 변경합니다. |
| <b>핫스팟 위치</b> <i>0.0 - 1.0</i> | 모양을 기준으로 핫스폿을 이동합니다. |
| <b>배경 사용</b> <i>거짓/참</i> | 단색으로 배경을 채울 수 있습니다. 이 경우 더 이상 혼합을 통해 이러한 오브젝트를 서로 연결할 수 없습니다. |
| <b>배경색</b> <i>(색상 값)</i> | 배경 단색을 설정합니다. |
| <b>텍스처 입력 사용</b> <i>거짓/참</i> | 미리 정의된 모양 유형 대신 사용자 정의 입력을 허용합니다. |
