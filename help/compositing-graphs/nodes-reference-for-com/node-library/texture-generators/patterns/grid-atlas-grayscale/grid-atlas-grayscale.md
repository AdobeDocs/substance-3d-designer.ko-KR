# 회색 음영 그리드 아틀라스

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![회색 음영 그리드 아틀라스 아이콘](grid-atlas-grayscale.resources/grid-atlas-grayscale.png "회색 음영 그리드 아틀라스")

## 설명

조정 가능한 XY 크기의 격자에 최대 16개의 회색 음영 이미지를 포장합니다.<br>출력 아틀라스 이미지는 [모양 스플래터 v2](../shape-splatter-v2/shape-splatter-v2.md) 또는 [모양 스플래터 매퍼 회색 음영](../shape-splatter-v2-mapper-grayscale/shape-splatter-v2-mapper-grayscale.md) 노드에서 샘플링할 수 있습니다.

[그리드 아틀라스 색상](../grid-atlas-color/grid-atlas-color.md)도 참조하세요.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

|                                   |                                                                                                                                                                                                                                                                                                                                                                    |
|:----------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>격자 크기 X</b> *정수* | X축에 있는 격자의 크기입니다.<br>즉, X축에 채워지는 이미지의 수입니다. |
| <b>격자 크기 Y</b> *정수* | Y축에 있는 격자의 크기입니다.<br>즉, Y축에 들어 있는 이미지의 수입니다. |
| <b>출력 크기 모드</b> *정수* | 노드의 &#39;출력 크기&#39; 기본 매개 변수에 따라 출력 이미지의 크기를 정의하는 방법:<br><br>- <b>수동:</b> 크기를 그대로 사용합니다.<br>- <b>자동 비율:</b> 이미지 크기를 최소화하려면 격자 크기에 따라 이미지 비율을 조정합니다. 세 개의 행 또는 열(예: (3, 2), (4, 3))을 사용하는 정사각형이 아닌 그리드에 대해 변형이 발생합니다. |
