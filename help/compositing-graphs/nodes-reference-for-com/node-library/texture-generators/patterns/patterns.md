# 패턴

패턴은 인공 그래픽으로 제작된 것처럼 보입니다. 그들은 주로 그들의 배치에 대한 규칙을 따르지만, 무작위 변이는 대부분 도입될 수 있다.

이 옵션은 벽돌, 타일, 직조된 패턴 등과 같은 일반 패턴을 기본으로 하려는 경우에 유용합니다.

거의 모든 패턴은 완벽하게 타일링되고 해상도와 독립적이므로 품질 손실 없이 크기를 조정할 수 있습니다.
