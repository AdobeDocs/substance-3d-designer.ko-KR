## 설명

조정 옵션을 사용하여 매끄러운 그레이디언트 다각형 모양을 생성합니다. 고급 버전은 [다각형 1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-1/polygon-1.md)을 참조하세요.

## 매개변수

|  |  |
|:---|:---|
| <b>면</b> <i>3 - 32</i> | 변의 양입니다. |
| <b>크기 조절</b> <i>0.0 - 1.0</i> | 전체 배율을 설정합니다. |
| <b>회전</b> <i>0.0 - 1.0</i> | 전체 모양을 회전합니다. |
| <b>곡선</b> <i>-1.0 - 1.0</i> | 그레이디언트 프로파일 곡선을 수정합니다. |
| <b>그레이디언트</b> <i>0.0 - 1.0</i> | 그레이디언트 대비를 조정합니다. |
| <b>그레이디언트 반전</b> <i>거짓/참</i> | 그레이디언트 방향을 반전시킵니다. |
| <b>자동 크기 조정</b> <i>거짓/참</i> | 기본 설정을 사용하여 캔버스에 맞게 크기를 조정합니다. |
| <b>비정사각형 확장</b> <i>거짓/참</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다. |
