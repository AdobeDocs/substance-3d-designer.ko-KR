## 설명

조정 옵션을 사용하여 매끄러운 그레이디언트 다각형 모양을 생성합니다. 고급 버전은 [다각형 1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-1/polygon-1.md)을 참조하세요.

## 매개변수

* **면**: *3 - 32*&#x200B;면의 양입니다.
* **크기 조절**: *0.0 - 1.0*&#x200B;전체 크기를 설정합니다.
* **회전**: *0.0 - 1.0*&#x200B;전체 모양을 회전합니다.
* **곡선**: *-1.0 - 1.0*&#x200B;그레이디언트 프로필 곡선을 수정합니다.
* **그레이디언트**: *0.0 - 1.0*&#x200B;그레이디언트 대비를 조정합니다.
* **그레이디언트 반전**: *False/True*&#x200B;그레이디언트 방향을 반전합니다.
* **자동 크기 조절**: *False/True*&#x200B;기본 설정으로 캔버스에 맞게 크기를 조정합니다.
* **비정사각형 확장**: *False/True*\
  제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다.
