## 설명

Tile Generator은 라이브러리에서 가장 진보된 노드 중 하나입니다. 마스터하는 방법을 알면 몇 가지 제한 사항 내에서 모든 종류의 패턴을 만들 수 있습니다. 버전 2017 2.1부터 이 노드가 [타일 Sampler](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-sampler/tile-sampler.md)에서 수행할 수 있는 작업에 더 잘 맞도록 큰 업데이트가 있었습니다.

이 노드는 다양한 시나리오에 매우 유용하지만 매개변수를 단순히 읽는 것만으로는 매개변수를 사용하는 방법을 완전히 알 수 없다는 점을 염두에 두십시오. 여러분도 실험해보시길 바랍니다!

모든 사례의 99%는 색상 버전이 필요하지 않습니다!

몇 가지 일반적인 사용 팁:

* 기본 모양으로 시작할 수 있지만 사용자 지정 입력(**패턴 유형**&#x200B;을 *이미지 입력*(으)로 설정)이 있는 경우 먼저 만드십시오! 그것은 많은 모습을 결정합니다.
* 먼저 X 및 Y 양을 올바르게 설정합니다.
* 올바른 **크기** 모드 찾기: **간격**&#x200B;과 같은 상대 모드는 **절대** 모드와 상당히 다르게 작동합니다.
* 다음으로 전역 **크기** 및 비균일 **크기**&#x200B;를 조정합니다.
* 마지막으로 필요에 맞게 **&quot;변형&quot;** 매개 변수를 조정합니다. 섬세함은 변형과 함께 핵심입니다!

<a name="inputs"></a>

## 입력

|  |  |
|:---|:---|
| <b>패턴 입력 1-6</b> <i>회색 음영 입력</i> | &quot;Pattern&quot; 매개 변수를 &quot;Image Input&quot;으로 설정한 경우 사용되는 사용자 정의 패턴 이미지입니다. |
| <b>배경</b> <i>회색 음영 입력</i> | 단색 대신 사용할 배경입니다. |

<a name="parameters"></a>

## 매개변수

|  |  |
|:---|:---|
| <b>X 양</b> <i>1 - 64</i> | 패턴의 X-반복의 양입니다. |
| <b>Y 양</b> <i>1 - 64</i> | 패턴의 Y-반복의 양입니다. |
| <b>비정사각형 확장</b> <i>거짓/참</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다. |
| <b>패턴</b> |  |
| <b>패턴</b> <i>이미지 입력, 정사각형, 디스크, 포물면, 벨, 가우스, 가시, 피라미드, 벽돌, 그라데이션, 파도, 하프 벨, 고정된 벨, 초승달, 캡슐, 원뿔</i> | 사용할 패턴 모양을 선택합니다. |
| <b>패턴 입력 번호</b> <i>1 - 6</i> | 사용할 서로 다른 이미지 입력 수입니다. 위에서 <i>이미지 입력</i>을 선택한 경우에만 사용할 수 있습니다. |
| <b>패턴 입력 분포</b> <i>패턴 번호별 무작위</i> | 1개 이상을 선택한 경우 서로 다른 이미지 입력 중에서 선택하는 방법입니다. |
| <b>패턴별</b> <i>0.0 - 1.0</i> | 선택한 패턴의 모양을 변경할 수 있습니다. 효과는 선택한 패턴에 따라 달라집니다. |
| <b>이미지 입력 필터링(엔진 >v4만 해당)</b> <i>쌍선형 + 밉맵, 쌍선형, 최근접</i> |  |
| <b>회전</b> <i>0, 90, 180, 270</i> | 모든 타일을 90도 단계로 설정된 각도만큼 전역적으로 회전합니다. |
| <b>회전 무작위</b> <i>0.0 - 1.0</i> | 란도미는 타일을 4개의 90도 단계 중 하나로 회전시킵니다. |
| <b>Quincunx 뒤집기</b> <i>거짓/참</i> | 타일을 90도 회전합니다. |
| <b>무작위 대칭</b> <i>0.0 - 1.0</i> | 선택한 대칭 무작위 모드 로 특정 패턴을 무작위로 미러링합니다. 이 값이 높을수록 더 많은 패턴이 미러링됩니다. |
| <b>대칭 무작위 모드</b> <i>가로 + 세로, 가로, 세로</i> | 대칭 난수가 0보다 큰 경우 미러링 동작을 결정합니다. |
| <b>크기</b> |  |
| <b>크기 모드</b> <i>표준 - 간격, 표준 - 크기, 비율 유지, 절대, 픽셀</i> | 패턴 크기의 일반 비헤이비어를 설정합니다.<br><br>표준 - 간격을 사용하면 패턴 요소 사이의 간격을 정의할 수 있습니다. X와 Y의 양에 영향을 받습니다.<br><br>보통 - 크기를 사용하면 간격에 관계없이 패턴 요소의 크기를 정의할 수 있습니다. X와 Y의 양에 영향을 받습니다.<br><br>비율 유지를 사용하면 X와 Y의 양에 따라 영향을 받는 크기를 설정할 수 있습니다. 그러나 둘 사이의 X와 Y 비율은 그대로 유지됩니다.<br><br>절대 크기를 사용하면 X 및 Y 크기의 영향을 받지 않는 절대 크기를 설정할 수 있습니다.<br><br>픽셀 을 사용하면 X 및 Y 양의 영향을 받지 않고 절대 크기를 픽셀 단위로 설정할 수 있습니다. 해상도를 변경하면 요소의 크기에 영향을 줍니다. |
| <b>중간 크기</b> <i>0.0 - 1.0</i> | 열과 행을 번갈아 가며 크기를 변경합니다. |
| <b>중간 X/Y</b> <i>0.0 - 1.0</i> | 표준 - 간격 크기 모드에서만 사용할 수 있습니다. 간격 간격을 변경합니다. 모양 사이의 이음새에 영향을 주므로 <b>비율</b>과 달리 균일하지 않은 제어가 가능합니다. |
| <b>크기(절대/픽셀)</b> <i>0.0 - 1.0</i> | 표준 - 중간 크기 모드 밖에서만 사용할 수 있습니다. <b>크기 조절</b>과 달리 크기가 일정하지 않습니다. |
| <b>크기 조절</b> <i>0.0 - 2.0</i> | 전체 배율을 설정합니다. |
| <b>무작위 크기 조정</b> <i>0.0 - 1.0</i> | 타일에 따른 전체 크기 조절 변화를 설정합니다. |
| <b>임의화 크기 조정</b> <i>0 - 1000</i> | 비율 변형 시드를 오프셋합니다. |
| <b>위치</b> |  |
| <b>오프셋</b> <i>0.0 - 1.0</i> | 모든 연속 행이나 열에 대해 전체 패턴을 점진적으로 오프셋합니다(비헤이비어는 수직 오프셋 매개변수에 따라 다름). |
| <b>임의 오프셋</b> <i>0.0 - 1.0</i> | 행 오프셋을 임의화합니다. |
| <b>오프셋 임의 시드</b> <i>0 - 1000</i> | 임의 오프셋 효과의 상대 초기값을 변경합니다. |
| <b>세로 오프셋</b> <i>거짓/참</i> | [오프셋] 효과가 행이나 선(가로 또는 세로)에 걸쳐 발생하는지 여부를 설정합니다. |
| <b>위치 무작위</b> <i>0.0 - 1.0</i> | X와 Y에 대해 별도의 컨트롤을 사용하여 균일하지 않은 방식으로 위치를 임의화합니다. |
| <b>전역 오프셋</b> <i>0.0 - 1.0</i> | X축과 Y축 모두에서 전체 결과를 이동합니다. |
| <b>회전</b> |  |
| <b>회전</b> <i>0.0 - 1.0</i> | 모든 패턴 타일의 자유 회전을 균일하게 수행합니다. |
| <b>회전 무작위</b> <i>0.0 - 1.0</i> | 모든 타일의 자유 회전을 임의화합니다. 이 값이 높을수록 타일을 더 많이 회전할 수 있습니다. |
| <b>색상</b> |  |
| <b>색상</b> <i>(회색 음영 값)</i> | 타일 단색을 설정합니다. |
| <b>광도/색상 무작위</b> <i>0.0 - 1.0</i> | 타일별 색상 또는 광도 변화를 소개합니다. |
| <b>숫자별 광도</b> <i>거짓/참</i> | 전체 패턴에서 광도를 희미하게 만듭니다. |
| <b>비율별 광도</b> <i>거짓/참</i> | 타일 비율에 따라 광도 변화가 달라집니다. |
| <b>검사기 마스크</b> <i>거짓/참</i> | 다른 모든 타일을 숨깁니다. |
| <b>수평 마스크</b> <i>거짓/참</i> | 다른 모든 열을 숨깁니다. |
| <b>세로 마스크</b> <i>거짓/참</i> | 다른 모든 행을 숨깁니다. |
| <b>무작위 마스크</b> <i>0.0 - 1.0</i> | 타일을 임의로 숨깁니다. 이 값이 높을수록 타일이 더 많이 사라집니다. |
| <b>마스크 반전</b> <i>거짓/참</i> | 이 섹션에서 마스크 효과의 결과를 반전합니다. |
| <b>혼합 모드</b> <i>추가, 최대, 하위 항목 추가</i> | 사용할 혼합 모드를 설정합니다. |
| <b>배경색</b> <i>(회색 음영 값)</i> | 단색 배경색을 설정합니다. |
| <b>전체 불투명도</b> <i>0.0 - 1.0</i> | 전체 타일 불투명도를 설정합니다. |
| <b>역렌더링 순서</b> <i>거짓/참</i> | 타일을 앞뒤로 또는 그 반대로 렌더링합니다. |
