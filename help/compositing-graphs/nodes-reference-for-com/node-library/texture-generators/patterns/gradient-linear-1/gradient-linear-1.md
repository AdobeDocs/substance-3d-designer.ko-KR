## 설명

간단한 흑백 선형 그레이디언트. 완벽한 그레이디언트 전환을 위해 완벽하게 매끄럽고 보간된 결과를 제공합니다.

단순함에도 불구하고, 이것은 많은 다른 노드들이 있는 빌딩 블록으로 사용될 수 있는 매우 유용한 패턴이다! 예를 들어 [막대 그래프 스캔](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/histogram-scan/histogram-scan.md)과 함께 사용해 보세요.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

|  |  |
|:---|:---|
| <b>타일링</b> <i>1 - 16</i> | 결과가 바둑판식으로 표시될 횟수를 설정합니다. |
| <b>회전</b> <i>0°, 90°, 180°, 270°</i> | 미리 정의된 각도를 따라 회전합니다. 그레이디언트의 방향을 변경합니다. |
