## 설명

뿌리기 원형 은 다양한 컨트롤을 사용하여 링 기반 패턴을 생성합니다. 미리 정의된 모양이나 사용자 정의 입력을 사용할 수 있습니다. [Tile Generator](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md)과(와) 비슷하지만 격자 대신 원형 배치가 있습니다.

이 기능은 다양한 임의화 옵션을 사용하여 모양을 원형 방식으로 배치하려는 경우에 유용합니다.

<a name="inputs"></a>

## 입력

두 입력 모두 선택 사항입니다.

|  |  |
|:---|:---|
| <b>패턴 이미지 입력 1-6</b> <i>회색 음영 입력(색상 입력)</i> | 스플래터 원형만: &quot;패턴&quot; 매개 변수가 &quot;이미지 입력&quot;으로 설정된 경우 사용되는 사용자 정의 패턴 이미지입니다. |
| <b>배경</b> <i>회색 음영 입력(색상 입력)</i> |  |

<a name="parameters"></a>

## 매개변수

|  |  |
|:---|:---|
| <b>패턴 양</b> <i>1 - 64</i> | 링에 배치할 패턴 타일의 양입니다. |
| <b>패턴 양 무작위</b> <i>0.0 - 1.0</i> | 배치할 패턴 양을 임의화합니다. 링 양이 1보다 큰 경우에 가장 적합합니다. |
| <b>패턴 양 임의 최소값</b> <i>1 - 10</i> | 임의화를 위한 패턴의 최소 양을 설정합니다. |
| <b>링 양</b> <i>1 - 10</i> | 채울 링 수를 설정합니다. 반지는 항상 바깥쪽 반지의 안쪽에 배치되며, 간격이 일정합니다. |
| <b>비정사각형 확장</b> <i>거짓/참</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다. |
| <b>패턴</b> |  |
| <b>패턴</b> <i>이미지 입력, 정사각형, 디스크, 포물면, 벨, 가우스, 가시, 피라미드, 벽돌, 그라데이션, 파도, 하프 벨, 고정된 벨, 초승달, 캡슐, 원뿔</i> | 사용할 패턴 모양을 선택합니다. |
| <b>패턴 입력 번호</b> <i>1 - 6</i> | 사용할 서로 다른 이미지 입력 수를 설정합니다. 위에서 <i>이미지 입력</i>을 선택한 경우에만 사용할 수 있습니다. |
| <b>패턴 입력 분포</b> <i>임의, 패턴 번호, 링 번호</i> | 여러 패턴 입력을 선택하는 방법을 설정합니다. 무작위란 임의의 것이 선택된 것을 의미하고, 패턴 숫자는 그것들이 단지 반복되는 순서에 놓여있다는 것을 의미하며, 고리 숫자는 모든 고리가 순서에 따라 다른 것을 의미한다. |
| <b>이미지 입력 필터링</b> <i>쌍선형 + 밉맵, 쌍선형, 최근접</i> |  |
| <b>패턴별</b> <i>0.0 - 1.0</i> | 선택한 패턴의 모양을 변경할 수 있습니다. 효과는 선택한 패턴에 따라 달라집니다. |
| <b>무작위 대칭</b> <i>0.0 - 1.0</i> | 아래 비헤이비어에 따라 임의로 뒤집거나 미러링할 타일 수를 설정합니다. |
| <b>대칭 무작위 모드</b> <i>가로 + 세로, 가로, 세로</i> | 대칭 미러링 동작을 결정합니다. |
| <b>위치</b> |  |
| <b>반경</b> <i>0.0 - 1.0</i> | 패턴이 배치되는 중심으로부터의 반경을 설정합니다. |
| <b>반경 무작위</b> <i>0.0 - 1.0</i> | 모든 패턴 타일에 대해 반경을 임의화합니다. |
| <b>링 반경 곱하기</b> <i>0.0 - 1.0</i> | 여러 고리의 간격에 영향을 줍니다. |
| <b>각도 무작위</b> <i>0.0 - 1.0</i> | 각 패턴의 각도를 임의화합니다. 양이 많을수록 회전이 많아집니다. |
| <b>나선형 요소</b> <i>0.0 - 1.0</i> | 링을 나선으로 바꾸고 모든 타일을 약간 증가하는 반경에 배치합니다. |
| <b>스프레드</b> <i>0.0 - 2.0</i> | 고리가 회전하는 양을 설정합니다. 이는 그 한계를 넘어 증가될 수 있다. |
| <b>방향을 따라 오프셋</b> <i>0.0 - 1.0</i> | 모든 패턴을 각도를 따라 중심에서 바깥쪽으로 이동합니다. 이 효과는 [각도 랜덤]에 따라 크게 달라지거나 [반경]에 대한 승수처럼 보입니다. |
| <b>전역 오프셋</b> <i>0.0 - 1.0</i> | 전체 모양을 변환합니다. |
| <b>크기</b> |  |
| <b>패턴 연결</b> <i>거짓/참</i> | 패턴 타일의 길이를 반지름에 따라 달라지게 합니다. 즉, 각 모양이 이전 모양과 다음 모양에 닿아야 합니다. |
| <b>크기(연결됨)</b> <i>0.0 - 1.0</i> | 각 패턴의 크기를 전역적으로 변경합니다. 연결된 경우 전체 반경을 기준으로 합니다. |
| <b>무작위 크기</b> <i>0.0 - 1.0</i> | 각 패턴의 크기를 개별적으로 임의화합니다. |
| <b>크기 조절</b> <i>0.0 - 2.0</i> | 각 패턴의 크기를 균일하게 조정합니다. |
| <b>무작위 크기 조정</b> <i>0.0 - 1.0</i> | 균일 비율을 임의화합니다. |
| <b>패턴 번호별 크기 조절</b> <i>0.0 - 1.0</i> | 패턴 배율이 링을 따라 배치된 위치에 따라 달라집니다. |
| <b>패턴 번호 반전</b> <i>거짓/참</i> | 이전 옵션과 함께 사용되는 이 기능을 사용하면 크기 조절을 작게 만들기에서 크게 만들 수 있으며 그 반대의 경우도 마찬가지입니다. |
| <b>링 번호별 크기 조정</b> <i>0.0 - 1.0</i> | 눈금이 링 번호에 종속되도록 합니다. |
| <b>링 번호 반전</b> <i>거짓/참</i> | 이전 옵션과 함께 사용하여 스몰에서 라지로 또는 그 반대로 비율을 반전할 수 있습니다. |
| <b>회전</b> |  |
| <b>패턴 회전</b> <i>0.0 - 1.0</i> | 모든 패턴을 균일하게 회전. |
| <b>패턴 회전 무작위</b> <i>0.0 - 1.0</i> | 패턴 회전을 임의화합니다. |
| <b>패턴 회전 피벗</b> <i>중앙, 최소 X, 최대 X, 최소 Y, 최대 Y</i> | 모든 패턴을 개별적으로 회전할 기준점 위치를 설정합니다. |
| <b>가운데 방향</b> <i>거짓/참</i> | 모든 패턴을 회전하여 링의 중심으로 이동합니다. 을 로 전환하면 모든 방향이 동일해집니다. 즉, 방향을 따라 오프셋 을 선택하면 원치 않는 효과가 발생할 수 있습니다. |
| <b>순환</b> <i>0.0 - 1.0</i> | 전체 링을 가운데를 중심으로 회전합니다. |
| <b>순환 임의 연결</b> <i>0.0 - 1.0</i> | 링마다 회전을 임의화합니다. |
| <b>링 회전 오프셋</b> <i>0.0 - 1.0</i> | 링당 회전을 오프셋합니다. |
| <b>색상</b> |  |
| <b>색상</b> <i>(회색 음영 값)</i> | 선택한 패턴으로 곱할 색상입니다. |
| <b>광도 무작위</b> <i>0.0 - 1.0</i> | 모든 패턴 타일에 대해 색상 또는 광도를 임의화합니다. |
| <b>비율별 광도</b> <i>0.0 - 1.0</i> | 개별 패턴 비율에 따라 광도가 달라집니다. |
| <b>패턴 번호별 광도</b> <i>0.0 - 1.0</i> | [광도]는 패턴 순서에 따라 달라집니다. 나선과 함께 사용할 수 있습니다. |
| <b>패턴 번호 반전</b> <i>거짓/참</i> | 이전 옵션을 반전시킵니다. |
| <b>링 번호별 광도</b> <i>0.0 - 1.0</i> | 링 시퀀스에 따라 광도를 달라지게 합니다. |
| <b>링 번호 반전</b> <i>거짓/참</i> | 이전 옵션을 반전시킵니다. |
| <b>무작위 마스크</b> <i>0.0 - 1.0</i> | 패턴을 임의로 숨깁니다. |
| <b>배경색</b> <i>(회색 음영 값)</i> | 단색 배경색을 변경합니다. |
| <b>혼합 모드</b> <i>추가, 최대, 하위 항목 추가</i> | 겹치는 패턴을 혼합하는 방법을 설정합니다. |
| <b>전체 불투명도</b> <i>0.0 - 1.0</i> | 전체 결과의 전체 불투명도를 설정합니다. |
