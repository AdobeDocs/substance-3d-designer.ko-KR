## 설명

타일링 각진 스트라이프 패턴을 생성합니다. 패턴은 항상 연속성을 보장하기 위해 자체적으로 조정됩니다.

## 매개변수

* **Stripe**: *1 - 100*&#x200B;줄무늬 양을 설정합니다. 타일링을 보장하기 위해 결과를 자동으로 이동합니다.
* **너비**: *0.0 - 1.0* Stripe 너비를 설정합니다.
* **부드러움**: *0.0 - 1.0*&#x200B;스트라이프 가장자리의 전환을 설정합니다.
* **Shift**: *0 - 20*&#x200B;줄무늬를 기울입니다. 자동으로 더 많은 줄무늬를 추가하여 타일링을 확인합니다.
* **정렬**: *가장자리, 가운데*&#x200B;이동을 위한 피벗을 설정합니다.
* **필터링**: *False/True*&#x200B;필터링을 사용합니다.
* **비정사각형 확장**: *False/True*\
  제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다.
