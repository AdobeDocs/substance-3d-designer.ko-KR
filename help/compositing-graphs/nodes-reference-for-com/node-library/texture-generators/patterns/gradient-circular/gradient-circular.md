## 설명

두 개의 사용자 정의 점으로 정의된 회색 음영 그라디언트 전환을 원형 방식으로 만듭니다. 전환은 a에서 b로의 전환이 아니라 1점을 중심으로 한 혁명으로서 2점에서 시작하고 끝난다. 결과가 바둑판식으로 배열되지 않는다는 점을 참고하십시오.

## 매개변수

|  |  |
|:---|:---|
| <b>지점 1</b> | 그레이디언트를 중심으로 회전하는 첫 번째 점은 가운데에 있을 필요가 없습니다 |
| <b>지점 2</b> | 그라디언트의 두 번째 지점인 |
| <b>비정사각형 확장</b> <i>거짓/참</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정합니다. |
