## 설명

**Tile Random 2** 노드는 임의의 크기 및 Height 대 너비 비율의 인접한 타일을 생성합니다.

그리드는 각을 분할하기 위해 모양의 측면을 무작위로 *경사*&#x200B;함으로써 조정될 수 있다.

모양은 *비율 조정*, *베벨링*, *모퉁이 둥글게 하기* 및 *회전되지 않은*&#x200B;에 대한 옵션으로 조정할 수 있습니다.

이러한 조정은 *입력 맵*&#x200B;에 의해 제어될 수 있습니다.

전용 출력을 사용하면 모양의 **UV**&#x200B;를 **Flood Fill 대상(...)**&#x200B;에 입력할 수 있습니다. 추가 변형을 적용하기 위한 노드입니다.

## 입력

|  |  |
|:---|:---|
| <b>임의 크기 맵</b> <i>회색 음영</i> | 모양의 무작위 비율을 제어하는 회색 음영 입력 이미지입니다.<br><br>해당 영향은 <b>임의 크기 입력 맵 승수</b> 매개 변수에 의해 제어됩니다. |
| <b>임의 기울임 맵</b> <i>회색 음영</i> | 모양의 무작위 경사를 제어하는 회색 음영 입력 이미지입니다.<br><br>해당 영향은 <b>임의 기울임 입력 맵 승수</b> 매개 변수에 의해 제어됩니다. |
| <b>둥근 모퉁이 반경 맵</b> <i>회색 음영</i> | 모양의 둥근 모퉁이 반경을 제어하는 회색 음영 입력 이미지입니다.<br><br>해당 영향은 <b>둥근 모퉁이 반경 입력 맵 Mult</b>에 의해 제어됩니다. 매개 변수. |
| <b>경사 거리 맵</b> <i>회색 음영</i> | 모양의 베일링을 제어하는 회색 음영 입력 이미지입니다.<br><br>해당 영향은 <b>경사 거리 입력 맵 Mult</b>에 의해 제어됩니다. 매개 변수. |
| <b>마스크 맵</b> <i>회색 음영</i> | 모양의 마스크를 제어하는 회색 음영 입력 이미지입니다.<br><br>해당 영향은 <b>마스크 맵 입력 시작</b> 및 <b>마스크 맵 입력 종료</b> 매개 변수에 의해 제어됩니다. |
