## 설명

다양한 조정 옵션을 사용하여 다각형 모양을 생성합니다. 더 간단한 버전은 [다각형 2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-2/polygon-2.md)을 참조하세요.

## 매개변수

* **면**: *3 - 32*&#x200B;다각형이 가져야 하는 면의 양을 설정합니다.
* **분해**: *0.0 - 1.0*&#x200B;다각형 &quot;분할 영역&quot;을 분리합니다.
* **삼각형 크기**: *0.0 - 1.0*&#x200B;분할 영역/삼각형의 크기를 조정합니다. 어떤 조정이든 모양을 분리할 수 있으며 이는 1,1개에 불과합니다. 이(가) 완벽하게 연결되었습니다!
* **크기 조절**: *0.0 - 1.0*&#x200B;전체 모양을 하나로 조정합니다.
* **자동 크기 조절**: *False/True*&#x200B;기본 매개 변수를 사용하여 전체 다각형이 보기에 맞도록 크기를 조정합니다.
* **회전**: *0.0 - 1.0*&#x200B;전체 모양을 회전합니다.
* **그레이디언트**: *False/True*&#x200B;단색 조각 대신 그레이디언트 조각/삼각형을 생성합니다. 참고: 이 설정이 활성화된 경우 다각형 2와 비슷해집니다.
* **그레이디언트 반전**: *False/True*&quot;그레이디언트&quot;가 활성화된 경우 그레이디언트 방향을 뒤집습니다.
* **타일링**: *1 - 16*\
  결과가 바둑판식으로 표시될 횟수를 설정합니다.
* **비정사각형 확장**: *False/True*\
  제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다.
* **정사각형이 아닌 타일링**&#x200B;**:** *False/True*비정사각형 확장을 사용하도록 설정하면 모양이 찌그러지지 않고 타일링됩니다.
