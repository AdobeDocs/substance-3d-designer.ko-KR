## 설명

이 노드는 몇 가지 옵션이 있는 단순한 직조 패턴을 생성합니다. 미리 정의된 직조 패턴보다 더 많은 제어를 가능하게 하며, 다른 노드로는 달성할 수 없는 패턴을 제시한다.

## 매개변수

|  |  |
|:---|:---|
| <b>타일 X</b> <i>1 - 20</i> | X축에서 반복되는 블록의 개수를 설정합니다. |
| <b>타일 Y</b> <i>1 - 20</i> | Y축에서 반복되는 블록의 수를 설정합니다. |
| <b>모양</b> <i>0.0 - 1.0</i> | 스티치의 곡선 Height 프로필을 설정합니다. |
| <b>직조</b> <i>1 - 10</i> | 블록당 몇 개의 스티치를 설정하세요. |
| <b>간격</b> <i>0.0 - 1.0</i> | X축과 Y축의 스티치 사이의 간격을 설정합니다. |
| <b>비정사각형 확장</b> <i>거짓/참</i> | 제곱이 아닌 비율로 스쿼시와 스트레치를 보정할 수 있습니다. |
