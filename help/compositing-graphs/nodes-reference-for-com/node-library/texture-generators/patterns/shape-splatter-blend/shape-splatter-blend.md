## 설명

[모양 튄 &#x200B;](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter/shape-splatter.md) 데이터를 입력으로 사용하여 색상 또는 회색 음영 맵을 생성합니다.

## 매개변수

* **배경색**: *색상 입력*
* **패턴 1-8**: *색상 입력*
* **색상 입력**: *색상 입력*
* **스플래터 데이터 1**: *색상 입력*
* **스플래터 데이터 2**: *색상 입력*

### 매개변수

* **패턴 번호**: *1 - 8*
* **임의 패턴 할당(색상만)**: *0.0 - 1.0*
* **&#x200B;표준 맵 &#x200B;**(색상만 해당)**&#x200B;**: *False/True*
* **HSL/광도 조정**: *-1.0 - 1.0*
* **HSL/광도 무작위**: *-1.0 - 1.0*
* **&#x200B;표준 각도 무작위 &#x200B;**(색상만 해당)**&#x200B;**: *0.0 - 1.0*
* **색상 입력 불투명도**: *0.0 - 1.0*
