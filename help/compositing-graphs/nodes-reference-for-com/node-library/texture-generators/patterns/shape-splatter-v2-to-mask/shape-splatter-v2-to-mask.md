# 마스킹할 모양 스플래터 v2

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![모양 스플래터 v2를 마스크 아이콘으로](shape-splatter-v2-to-mask.png "모양 스플래터 v2를 마스크로")

<b>내부:</b> 생성기 > 패턴

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 설명

[모양 스플래터 v2](../shape-splatter-v2/shape-splatter-v2.md) Height에서 생성된 모양의 선택 영역에서 마스크를 계산합니다.<br><br>사용 가능한 옵션에는 임의 선택뿐만 아니라 고유 식별자 및/또는 재질 ID/패턴 ID*에 의한 모양의 범위 선택도 포함됩니다.<br><br>모양은 <i>Height 혼합</i>에서 [모양 스플래터 v2](../shape-splatter-v2/shape-splatter-v2.md) 노드에 의해 배경 노드로 사전 마스킹됩니다.<br>배경과 선택하지 않은 모양이 모두 완전히 검정색입니다. (즉, 0)<br><br><b>*:</b> 모양 스플래터 UVW 입력에서 검색된 값 중 하나는 모양 스플래터 v2 그리드 아틀라스:<br>- <i>SDF/프리미티브</i>에 사용된 <b>모양 유형</b>에 따라 재질 ID 또는 패턴 ID입니다. 재질 ID<br>- <i>패턴 입력/노드:</i> 패턴 ID, 즉 목록/아틀라스의 패턴 인덱스입니다.

</td>
</tr>
</table>

> * [모양 스플래터 v2 매퍼 색상](../shape-splatter-v2-mapper-color/shape-splatter-v2-mapper-color.md)

<a name="inputs"></a>

## 입력

|                             |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:----------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>Splatter UVW</b> *색상* | <b>R</b> - 모양의 UV 구성 요소<br><b>G</b> - 모양의 UV 구성 요소<br><b>B</b> - 모양의 Height. (W)<br><b>A</b> - 압축된 데이터:<br> - <i>정수 부분:</i> 모양의 고유 식별자입니다. (ID)<br> - <i>분수 부분:</i>은(는) <b>모양 유형</b>에 따라 다릅니다. 재질 ID(SDF/기본 형식인 경우), 패턴 ID*(패턴 입력/그리드 아틀라스인 경우).<br><br><b>*:</b> 패턴 ID는 목록/아틀라스에 있는 모양의 인덱스입니다. |

<a name="outputs"></a>

## 출력

|               |                                           |
|:--------------|:------------------------------------------|
| <b>출력</b> | 선택한 모양의 계산된 마스크입니다. |

<a name="parameters"></a>

## 매개변수

|                                                         |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:--------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>출력</b> *정수* | 출력 마스크에서 선택한 모양에 사용되는 값입니다.<br><br>- <b>이진 마스크:</b> 선택한 모양은 모두 1.<br>- <b>모양 ID(정수):</b> 선택한 모양은 고유한 식별자를 사용합니다. (ID)<br>- <b>재질 ID(정수):</b> 선택한 모양은 해당 재질 ID를 사용합니다.<br>- <b>모양 ID(정규화됨):</b> 선택한 모양은 가장 낮은 선택한 ID에서 가장 높은 범위까지 [0, 1] 범위에 매핑된 고유 식별자(ID)를 사용합니다.<br>- <b>재질 ID(정규화됨):</b> 선택한 모양은 가장 낮은 선택한 재질 ID에서 가장 높은 범위까지 [0, 1] 범위에 매핑된 해당 재질 ID를 사용합니다. |
| <b>셰이프 ID 시작 범위</b> *정수* | 선택 범위의 시작으로 사용되는 모양 고유 식별자(ID)입니다. (포함됨) |
| <b>셰이프 ID 종료 범위</b> *정수* | 선택 범위의 끝으로 사용되는 모양 고유 식별자(ID)입니다. (포함됨) |
| <b>모양 ID 오프셋</b> *정수* | 선택 범위의 컨텍스트에서 모양의 고유 식별자를 지정된 값으로 오프셋합니다.<br><br>이렇게 하면 시작 및 끝 경계를 수동으로 조정할 필요 없이 현재 선택 영역을 지정한 값만큼 쉽게 오프셋할 수 있습니다. |
| <b>재질/패턴 ID 마스크 조합</b> *정수* | 고유 식별자(ID)에 의한 선택 항목과 재질 ID/패턴 ID에 의한 선택 항목을 결합하는 데 사용되는 논리 연산자를 지정했습니다.<br><br>- <b>없음:</b> 선택 항목에 대한 재질 ID/패턴 ID를 완전히 무시합니다.<br>- <b>및:</b> 선택한 모양은 ID 및 재질 ID/패턴 ID 범위 모두에 포함되어야 합니다. (더 적은 모양 포함)<br>- <b>또는:</b> 선택한 모양이 ID 또는 재질 ID/패턴 ID 범위에 포함되어야 합니다. (더 많은 모양 포함) |
| <b>재료/패턴 ID 시작 범위</b> *정수* | 선택 범위의 시작 부분으로 사용되는 재료 ID 또는 패턴 ID*입니다. (포함됨)<br><br><b>*:</b> 자세한 내용은 노드 설명을 참조하십시오. |
| <b>재료/패턴 ID 끝 범위</b> *정수* | 선택 범위의 끝으로 사용되는 재료 ID 또는 패턴 ID*입니다. (포함됨)<br><br><b>*:</b> 자세한 내용은 노드 설명을 참조하십시오. |
| <b>모양 무작위 마스크</b> *부동* | 모양의 임의 마스킹에 대한 인수입니다. 여기서 1은 모든 모양이 마스킹됨을 의미합니다. |
