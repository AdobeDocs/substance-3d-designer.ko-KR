## 설명

패스 형식으로 기본(다각형)을 생성합니다.

[패스 2D 변형](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/path-2d-transform/path-2d-transform.md) 노드를 사용하여 기본 모양을 정확하게 배치합니다.

<a name="outputs"></a>

## 출력

|  |  |
|:---|:---|
| <b>경로</b> <i>색상</i> | 인코딩된 세그먼트 목록을 설명하는 인코딩된 경로 목록을 포함합니다.<br>직접 사용하거나 수정하도록 들여쓰지 않았습니다. 호환 가능한 노드를 찾으려면 경로를 검색합니다. |

<a name="parameters"></a>

## 매개변수

|  |  |
|:---|:---|
| <b>변의 수</b> <i>정수</i> | 팁: 100에서 1000 사이의 숫자를 입력하여 원을 생성합니다. |
