# 경로 도구

패스 도구는 패스를 생성 및 조정하고, 복잡한 이미지의 산란이나 뒤틀기를 위해 스플라인으로 변환하기 위한 노드의 컬렉션입니다.

패스는 직선으로 연결된 일련의 점입니다.

시작하려면 이 튜토리얼을 확인하십시오.

>[!TIP]
>
> 도구 집합을 최대한 활용하기 위해 [경로 및 자유 곡선 도구 작업](../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/working-with-path-and-spl/working-with-path-and-spline-tools.md)에 대해 배우는 것이 좋습니다.
> 
> 고급 사용자를 위해 [패스 형식 사양](../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/paths-format-spe/paths-format-specifications.md)에서는 패스의 데이터를 컬러 이미지로 인코딩하는 방법을 설명하고 이 데이터를 직접 조작하기 위한 팁을 제공합니다.
