# 스플라인 및 패스 도구

스플라인 및 패스 도구 는 Substance 그래프에서 패스 및 스플라인을 사용하여 작업하기 위한 노드 컬렉션입니다.

<b>패스</b>는 직선으로 연결된 일련의 점입니다.

<b>스플라인</b>은 제어점과 해당 점의 접선에 의해 궤도 모양이 형성되는 매끄러운 곡선입니다. 또한 각 점은 이미지의 매핑, 뒤틀기 및 산포를 제어하는 데 사용되는 스플라인의 Height 및 Thickness 특성을 제어합니다.

이 범주에는 다음과 같은 하위 범주가 포함됩니다.

* [자유 곡선 도구](../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/spline-tools.md)\
  스플라인을 생성 및 조정하고, 이미지 매핑, 분산 또는 뒤틀기에 사용하는 노드
* [패스 도구](../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/path-tools.md)패스를 생성 및 조정하고 이미지의 복잡한 분산 또는 뒤틀기를 위해 스플라인으로 변환하기 위한 노드.

시작하려면 다음 튜토리얼을 확인하십시오.

>[!TIP]
>
> 도구 집합을 최대한 활용하기 위해 [경로 및 자유 곡선 도구 작업](../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/working-with-path-and-spl/working-with-path-and-spline-tools.md)에 대해 배우는 것이 좋습니다.
