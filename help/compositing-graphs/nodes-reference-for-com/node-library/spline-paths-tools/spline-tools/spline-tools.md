# 자유 곡선 도구

자유 곡선 도구는 스플라인을 생성 및 조정하고, 이미지 매핑, 분산 또는 뒤틀기 작업에 사용하기 위한 노드의 컬렉션입니다.

스플라인은 제어점과 제어점의 접선에 의해 궤적의 모양이 형성되는 매끄러운 곡선입니다. 또한 각 점은 이미지의 매핑, 뒤틀기 및 산포를 제어하는 데 사용되는 스플라인의 Height 및 Thickness 특성을 제어합니다.

시작하려면 이 튜토리얼을 확인하십시오.

>[!TIP]
>
> 도구 집합을 최대한 활용하기 위해 [경로 및 자유 곡선 도구 작업](../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/working-with-path-and-spl/working-with-path-and-spline-tools.md)에 대해 배우는 것이 좋습니다.
