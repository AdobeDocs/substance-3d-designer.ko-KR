노드는 패턴 분산 방식을 제어하는 심층 사용자 정의 옵션을 제공합니다

산란의 일부 양태들은 결과의 동적 양태를 더 추가하기 위해 그래프 내의 다른 노드들로부터의 이미지들을 사용하여 제어될 수 있다.

>[!NOTE]
>
> 자세한 내용은 [스플라인 회색 음영 산란](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/scatter-spline-grayscale/scatter-on-spline-grayscale.md)를 참조하세요.

## 입력 커넥터

<b>배경&#x200B;</b>*회색 음영*(기본)스플라인을 그려야 하는 회색 음영 이미지입니다.

<b>스플라인 좌표&#x200B;</b>*색상*&#x200B;색상 이미지의 RGBA 채널로 인코딩된 입력 스플라인의 점 좌표:\
<b>R</b> - X 위치\
<b>G</b> - Y 위치\
<b>B</b> - Height\
<b>A</b> - 압축된 데이터:\
* Sign: 스플라인이 닫히거나(음수) 열림(양수);\
* 절대값: Thickness + 1.

<b>스플라인 데이터</b> *색상*&#x200B;색상 이미지의 RGBA 채널로 인코딩된 입력 스플라인의 추가 데이터입니다.\
<b> R</b> - 접선 X\
<b> G</b> - 접선 Y\
<b> B</b> - 미사용\
<b> A</b> - 미사용

<b>스플라인 양</b> *정수*&#x200B;입력 스플라인 수입니다.

<b>패턴 입력 #</b> *회색 음영*&#x200B;스플라인을 따라 흩어져야 하는 패턴입니다.

<b>지도 크기 조절</b> *회색 음영*&#x200B;흩어진 패턴의 비율을 제어하는 맵입니다. 이 맵의 효과는 &#39;비율 맵 입력 승수&#39; 매개변수에 의해 제어되며 &#39;크기&#39; 그룹의 다른 매개변수와 결합됩니다.

<b>Height 맵</b> *회색 음영*&#x200B;흩어진 패턴의 Height을 제어하는 맵입니다. 이 맵의 효과는 &#39;Height 입력 승수&#39; 매개 변수에 의해 제어되며 &#39;색상&#39; 그룹의 다른 &#39;색상&#39; 매개 변수와 결합됩니다.

<b>마스크 맵</b> *회색 음영*&#x200B;흩어진 패턴의 마스크를 제어하는 맵입니다. 이 맵의 효과는 &#39;마스크 맵 임계값&#39; 매개 변수에 의해 제어되고 &#39;색상&#39; 그룹의 다른 &#39;마스크&#39; 매개 변수와 결합됩니다.

## 출력 커넥터

<b>출력</b> *회색 음영*&#x200B;입력 배경 위의 입력 스플라인을 따라 흩어진 패턴을 나타내는 이미지입니다.

## 매개변수

<b>스플라인 입력</b> *정수*&#x200B;분산 패턴에 사용할 스플라인을 선택하는 방법:
* *모든 스플라인*: 입력 목록의 모든 스플라인을 사용합니다.
* *단일 스플라인*: 입력 목록에서 지정한 스플라인만 사용합니다.
* *스플라인 범위*: 입력 목록에서 지정된 범위의 스플라인만 사용합니다.

<b>스플라인 인덱스</b> *정수*(&#39;스플라인 입력&#39;이 &#39;단일 스플라인&#39;으로 설정된 경우 사용 가능)분산 패턴에 사용해야 하는 스플라인의 목록 인덱스입니다.

<b>스플라인 범위</b> *정수2*(&#39;스플라인 입력&#39;이 &#39;스플라인 범위&#39;로 설정된 경우 사용 가능)분산 패턴에 사용해야 하는 스플라인을 포함하는 목록 인덱스의 범위입니다.

<b>산란 모드</b> *정수*&#x200B;스플라인을 따라 패턴을 분산하는 방법으로, 각 스플라인의 패턴 양에 영향을 줍니다.
* 모양 양: 간격이 균일한 지정된 패턴의 양이 흩어집니다.
* 모양 간격: 패턴 수는 지정된 짝수 간격에 맞게 자동으로 조정됩니다.\
  두 경우 모두 첫 번째 및 마지막 패턴이 각 스플라인의 시작과 끝에 각각 정확히 떨어집니다.

<b>모양 양</b> *정수*(&#39;산란 모드&#39;가 &#39;모양 양&#39;으로 설정된 경우 사용 가능)각 스플라인을 따라 흩어져 있는 간격이 균일한 패턴의 양입니다.

<b>스플라인을 따라 모양 분포</b> *정수*(&#39;산란 모드&#39;가 &#39;모양 양&#39;으로 설정된 경우 사용 가능)스플라인을 따라 패턴을 분포하는 방법:
* *원본에서*: 패턴의 간격은 스플라인 점의 접선에 영향을 받습니다. 여기서 모양은 긴 접선이 있는 지점 근처에서 더 멀리 떨어져 있습니다.
* *균일*: 패턴은 접선 및 궤적에 관계없이 스플라인을 따라 균일한 간격으로 배치됩니다.

<b>모양 간격</b> *Float*(&#39;산란 모드&#39;가 &#39;모양 간격&#39;으로 설정된 경우 사용 가능)각 스플라인의 시작과 끝에 첫 번째 및 마지막 패턴을 각각 놓고 있는 동안 패턴이 간격을 두어야 하는 스플라인을 따르는 최소 거리입니다.

<b>시작</b> *부동*&#x200B;산포가 시작되는 스플라인의 시작점에서 점을 오프셋합니다. 값은 각 스플라인의 표준화된 길이입니다.

<b>종료</b> *부동*&#x200B;산란이 끝나는 스플라인의 시작점에서 점을 오프셋합니다. 값은 각 스플라인의 표준화된 길이입니다.

<b>모양 피벗</b> *Float2*&#x200B;스플라인 탄젠트 공간에서 패턴 X 및 Y의 피벗을 오프셋합니다.\
스플라인에 피벗이 배치되는 것을 고려하면 스플라인을 따라 또는 스플라인에 수직으로 패턴을 효과적으로 오프셋합니다.\
참고: 피벗의 위치는 &#39;배율&#39; 및 &#39;회전(피벗)&#39; 매개 변수의 효과에 영향을 줍니다.

+++패턴
<b>패턴</b> *정수*&#x200B;스플라인을 따라 분산되어야 하는 패턴:\
*- 패턴 입력*: &#39;패턴 입력 #&#39; 입력에 제공된 패턴을 사용합니다.\
*- 정사각형;
* 디스크;
* 포물면
* 벨;
* 가우스;
* 가시;
* 피라미드;
* 벽돌;
* 그라데이션
* 웨이브;
* 하프 벨;
* 제야의 종;
* 초승달
* 캡슐;
* Cone;
* 그라데이션 w. offset;
* 반구.*

<b>패턴 입력 번호</b> *정수*(&#39;패턴&#39;이 &#39;패턴 입력&#39;으로 설정된 경우 사용 가능)분산되어야 하는 입력 패턴의 인덱스를 선택합니다.

<b>패턴 입력 분포</b> *정수*(&#39;패턴&#39;이 &#39;패턴 입력&#39;으로 설정되어 있을 때 사용 가능)특정 스플라인에 분산되어야 하는 입력 패턴을 선택하는 데 사용되는 방법:\
*- 무작위*: 패턴이 임의로 선택되었습니다.\
*- 스플라인을 따라*: 패턴 색인이 스플라인을 따라 점진적으로 증가합니다.\
*- 패턴 인덱스*: 각 스플라인을 따라 입력 패턴의 인덱스 위에 루프를 만듭니다.\
*- 스플라인 인덱스*: 입력 스플라인 목록의 한 스플라인에서 다음 스플라인으로 입력 패턴의 인덱스를 반복합니다.

<b>배포 지터링</b> *부동*(&#39;패턴 입력 분포&#39;가 &#39;스플라인 따라&#39;로 설정된 경우 사용 가능)스플라인에서 선택한 패턴 인덱스를 임의로 늘리거나 줄입니다.

<b>첫 번째 패턴 재정의</b> *부울*&#x200B;각 스플라인의 시작 부분에 배치해야 하는 패턴의 인덱스를 수동으로 선택합니다.

<b>첫 번째 패턴 입력 인덱스</b> *정수*(&#39;첫 번째 패턴 재정의&#39;가 &#39;True&#39;로 설정된 경우 사용 가능)각 스플라인의 시작 부분에 배치되어야 하는 패턴의 인덱스입니다.

<b>마지막 패턴 재정의</b> *부울*&#x200B;각 스플라인의 끝에 배치해야 하는 패턴의 인덱스를 수동으로 선택합니다.

<b>마지막 패턴 입력 인덱스</b> *정수*(&#39;마지막 패턴 재정의&#39;가 &#39;True&#39;로 설정된 경우 사용 가능)각 스플라인의 끝에 배치되어야 하는 패턴의 인덱스입니다.

+++

+++중복
<b>배포 모드</b> *정수*&#x200B;중복 패턴을 배치하는 데 사용되는 메서드입니다.\
*- 선형*: 중복은 패턴의 원래 위치에서 스플라인의 법선을 따라 균등하게 간격을 두고 있습니다.\
*- 원형*: 패턴의 원래 위치에서 스플라인을 중심으로 하는 가상 원을 따라 복제되어 정렬됩니다.

<b>중복 양</b> *정수*&#x200B;복제된 패턴 수입니다.

<b>오프셋</b> *Float2*(&#39;분포 모드&#39;가 &#39;선형&#39;으로 설정된 경우 사용 가능)스플라인의 탄젠트(평행) 및 수직(수직)을 따라 중복 위치에 오프셋을 적용합니다.\
스플라인의 반대쪽에 있는 중복은 반대 방향으로 이동됩니다.

<b>오프셋 가운데</b> *Float2*(&#39;분포 모드&#39;가 &#39;선형&#39;으로 설정되어 있을 때 사용 가능)X(평행) 및 Y(수직)의 스플라인을 따라 중복에 오프셋을 적용합니다.

<b>스프레드 각도</b> *부동*(&#39;배포 모드&#39;가 &#39;원형&#39;으로 설정되어 있을 때 사용 가능)중복이 배포되는 가상 원의 원호입니다. 원호의 각도는 1이 전체 원입니다.

<b>오프셋 거리</b> *부동*(&#39;배포 모드&#39;가 &#39;원형&#39;으로 설정된 경우 사용 가능)중복이 배포되는 가상 원의 반경입니다.

<b>회전</b> *부동*&#x200B;중복이 배포되는 가상 원을 회전합니다.

<b>오프셋 시작/끝 감쇠</b> 중복에 오프셋을 적용할 때 스플라인의 중간점에서 시작 및 끝까지의 거리에 있는 *Float2*&#x200B;인자입니다.\
즉, 스플라인의 가장자리에 가까운 중복에 대해서는 오프셋이 줄어듭니다.

<b>Thickness 오프셋 감쇠</b> 중복에 오프셋을 적용할 때 스플라인의 Thickness에 *요소를 부동*&#x200B;합니다.\
즉, 낮은 Thickness을 사용하는 스플라인의 일부에서 중복에 대한 오프셋이 줄어듭니다.

+++

+++크기
<b>크기 모드</b> *정수*&#x200B;흩어진 패턴의 크기를 설정하는 방법입니다.\
*- 표준*: 전역 &#39;Scale&#39; 매개 변수를 사용하여 크기가 균일하게 제어됩니다.\
*- 스플라인에서 Thickness 사용*: 스플라인의 Thickness에 따라 크기가 제어됩니다.

<b>Thickness 영향</b> *정수*(&#39;크기 모드&#39;가 &#39;스플라인에서 Thickness 사용&#39;으로 설정되어 있을 때 사용 가능)스플라인의 Thickness으로 제어할 패턴 비율의 축을 지정합니다.
* X 및 Y: Thickness이 X 및 Y 축 모두의 크기에 대해 곱해집니다.
* X: Thickness이 X축의 크기에만 곱해집니다.
* Y: Thickness은 Y축의 크기에만 곱해집니다.\
  곱하지 않으면 패턴의 원래 배율이 이미지의 전체 범위입니다.\
  즉, &#39;X&#39; 모드에서 Y축의 크기는 이미지의 전체 범위이며 크기 매개 변수를 사용하여 조정해야 합니다. &#39;Y&#39; 모드를 사용하는 경우 X축의 크기도 동일하게 적용됩니다.

<b>크기</b> *Float2*&#x200B;다른 매개 변수에 의해 다른 조정이 이루어지기 전의 X 및 Y 패턴의 원래 크기입니다.

<b>무작위 크기</b> *Float2* X 및 Y의 패턴 크기를 줄이기 위해 지정된 값까지 무작위 승수를 적용합니다.

<b>Thickness 크기</b> *Float*(&#39;크기 모드&#39;가 &#39;스플라인에서 Thickness 사용&#39;으로 설정된 경우 사용 가능)스플라인의 Thickness으로 제어되는 경우 패턴의 비율에 대한 추가 승수입니다.

<b>크기 조절</b> *부동*(&#39;크기 모드&#39;가 &#39;표준&#39;으로 설정된 경우 사용 가능)모든 패턴의 크기에 대한 전역 컨트롤입니다. 여기서 1은 이미지의 전체 범위입니다.\
