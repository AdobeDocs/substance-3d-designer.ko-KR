노드는 패턴 분산 방식을 제어하는 심층 사용자 정의 옵션을 제공합니다

산란의 일부 양태들은 결과의 동적 양태를 더 추가하기 위해 그래프 내의 다른 노드들로부터의 이미지들을 사용하여 제어될 수 있다.

>[!NOTE]
>
> 자세한 내용은 [스플라인 회색 음영 산란](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/scatter-spline-grayscale/scatter-on-spline-grayscale.md)를 참조하세요.

<a name="inputs"></a>

## 입력

|  |  |
|:---|:---|
| <b>배경</b> <i>회색 음영</i>(기본) | 스플라인을 그릴 회색 음영 이미지입니다. |
| <b>스플라인 코드</b> <i>색상</i> | 색상 이미지의 RGBA 채널로 인코딩된 입력 스플라인의 좌표:<br><b>R</b> - X 위치<br><b>G</b> - Y 위치<br><b>B</b> - Height<br><b>A</b> - 압축된 데이터:<br> * 기호: 스플라인이 닫힘(네거티브) 또는 열림(포지티브);<br> * 절대값: Thickness + 1. |
| <b>스플라인 데이터</b> <i>색상</i> | 색상 이미지의 RGBA 채널에 인코딩된 입력 스플라인의 추가 데이터입니다.<br><b>R</b> - 탄젠트 X<br><b>G</b> - 탄젠트 Y<br><b>B</b> - 미사용<br><b>A</b> - 미사용 |
| <b>스플라인 양</b> <i>정수</i> | 입력 스플라인의 수입니다. |
| <b>패턴 입력 #</b> <i>회색 음영</i> | 스플라인을 따라 분산되어야 하는 패턴. |
| <b>지도 크기 조절</b> <i>회색 음영</i> | 흩어진 패턴의 비율을 제어하는 맵입니다. 이 맵의 효과는 &#39;비율 맵 입력 승수&#39; 매개변수에 의해 제어되며 &#39;크기&#39; 그룹의 다른 매개변수와 결합됩니다. |
| <b>Height 맵</b> <i>회색 음영</i> | 흩어져 있는 패턴의 Height을 제어하는 맵입니다. 이 맵의 효과는 &#39;Height 입력 승수&#39; 매개 변수에 의해 제어되며 &#39;색상&#39; 그룹의 다른 &#39;색상&#39; 매개 변수와 결합됩니다. |
| <b>마스크 맵</b> <i>회색 음영</i> | 분산된 패턴의 마스킹을 제어하는 맵입니다. 이 맵의 효과는 &#39;마스크 맵 임계값&#39; 매개 변수에 의해 제어되고 &#39;색상&#39; 그룹의 다른 &#39;마스크&#39; 매개 변수와 결합됩니다. |

| <b>종료</b> <i>부동</i> | 산란이 끝나는 스플라인의 시작점에서 점을 오프셋합니다. 값은 각 스플라인의 표준화된 길이입니다. |
| <b>모양 피벗</b> <i>Float2</i> | 스플라인 탄젠트 공간에서 패턴 X 및 Y의 피벗을 오프셋합니다.<br>피벗이 스플라인에 배치된 것으로 간주하면 스플라인을 따라 또는 스플라인에 수직으로 패턴을 효과적으로 오프셋합니다.<br>참고: 피벗의 위치는 &#39;배율&#39; 및 &#39;회전(피벗)&#39; 매개 변수의 효과에 영향을 줍니다. |
| <b>패턴</b> |  |

| <b>배포 지터링</b> <i>부동</i>(&#39;패턴 입력 분포&#39;가 &#39;스플라인 따라&#39;으로 설정된 경우 사용 가능) | 스플라인에서 선택한 패턴 인덱스를 임의로 늘리거나 줄입니다. |
| <b>첫 번째 패턴 재정의</b> <i>부울</i> | 각 스플라인의 시작 부분에 배치해야 하는 패턴의 인덱스를 수동으로 선택합니다. |
| <b>첫 번째 패턴 입력 인덱스</b> <i>정수</i>(&#39;첫 번째 패턴 재정의&#39;가 &#39;True&#39;로 설정된 경우 사용 가능) | 각 스플라인의 시작 부분에 배치해야 하는 패턴의 인덱스입니다. |
| <b>마지막 패턴 재정의</b> <i>부울</i> | 각 스플라인의 끝에 배치해야 하는 패턴의 인덱스를 수동으로 선택합니다. |
| <b>마지막 패턴 입력 인덱스</b> <i>정수</i>(&#39;마지막 패턴 재정의&#39;가 &#39;True&#39;로 설정된 경우 사용 가능) | 각 스플라인의 끝에 배치해야 하는 패턴의 인덱스입니다. |
| <b>중복</b> |  |

| <b>오프셋 거리</b> <i>부동</i>(&#39;배포 모드&#39;가 &#39;원형&#39;으로 설정된 경우 사용 가능) | 중복이 배포되는 가상 원의 반경입니다. |

| <b>오프셋 시작/끝 감쇠</b> <i>Float2</i> | 중복에 오프셋을 적용할 때 스플라인의 중간점부터 시작점 및 끝점까지의 거리에 있는 인자입니다.<br>스플라인의 가장자리에 가까운 중복에 대해서는 오프셋이 줄어듭니다. |
| <b>Thickness 오프셋 감쇠</b> <i>부동</i> | 중복에 오프셋을 적용할 때 스플라인 Thickness의 요소<br>낮은 Thickness의 스플라인 부분에서 중복에 대한 오프셋이 줄어듭니다. |
| <b>크기</b> |  |

| <b>Thickness 영향</b> <i>정수</i>(&#39;크기 모드&#39;가 &#39;스플라인에서 Thickness 사용&#39;으로 설정된 경우 사용 가능) | 스플라인의 Thickness에 의해 제어되어야 하는 패턴 비율 축을 지정합니다.<br>* X &amp; Y: Thickness의 크기가 X 및 Y축의 크기에 대해 곱해집니다.<br>* X: Thickness의 크기가 X축의 크기에 대해서만 곱해집니다.<br>* Y: Thickness의 크기가 Y축의 크기에 대해서만 곱해집니다.<br>곱하지 않으면 패턴의 원래 배율이 이미지의 전체 범위입니다.<br>이것은 &#39;X&#39; 모드에서 Y축의 크기가 이미지의 전체 범위이며 크기 매개 변수를 사용하여 조정해야 함을 의미합니다. &#39;Y&#39; 모드를 사용하는 경우 X축의 크기도 동일하게 적용됩니다. |
