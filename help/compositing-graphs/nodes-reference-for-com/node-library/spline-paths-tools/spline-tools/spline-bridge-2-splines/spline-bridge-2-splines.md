# 스플라인 브리지(스플라인 2개)

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![노드 아이콘](spline-bridge-2-splines.resources/spline-bridge-2splines-icon.png "노드 아이콘")

<b>인:</b> 스플라인 및 패스 도구 > 자유 곡선 도구

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 설명

이러한 스플라인을 따라 <b>스플라인 #1</b>에서 <b>스플라인 #2</b>까지 스플라인을 생성합니다. 생성된 스플라인은 [선형] (직선) 또는 [입방 베지어] (곡선)일 수 있습니다.

</td>
</tr>
</table>

>[!IMPORTANT]
>
> <b>스플라인 #1</b> 및 <b>스플라인 #2</b> 입력에 제공된 데이터에 두 개 이상의 스플라인이 포함된 경우 각 목록의 마지막 스플라인만 사용됩니다.

<a name="inputs"></a>

## 입력

|  |  |
|:---|:---|
| <b>미리 보기 #1</b> <i>회색 음영</i> | 입력 스플라인의 미리보기가 회색 음영 이미지로 #1. |
| <b>스플라인 #1</b> <i>색상</i> | 입력 스플라인의 좌표#1 색상 이미지의 RGBA 채널로 인코딩됩니다.<br><b>R</b> - X 위치<br><b>G</b> - Y 위치<br><b>B</b> - Height<br><b>A</b> - 압축된 데이터:<br>- 기호: 스플라인이 닫히거나(음수) 열림(양수);<br>- 절대값: Thickness + 1. |
| <b>스플라인 데이터 #1</b> <i>색상</i> | 입력 스플라인의 추가 데이터#1 색상 이미지의 RGBA 채널로 인코딩됩니다.<br><b>R</b> - 탄젠트 X<br><b>G</b> - 탄젠트 Y<br><b>B</b> - 미사용<br><b>A</b> - 미사용 |
| <b>스플라인 양 #1</b> <i>정수</i> | 입력 스플라인 수가 #1. |
| <b>미리 보기 #2</b> <i>회색 음영</i> | 입력 스플라인의 미리보기가 회색 음영 이미지로 #2. |
| <b>스플라인 #2</b> <i>색상</i> | 색상 이미지의 RGBA 채널로 인코딩된 입력 스플라인의 #2 좌표입니다.<br><b>R</b> - X 위치<br><b>G</b> - Y 위치<br><b>B</b> - Height<br><b>A</b> - 압축된 데이터:<br>- 기호: 스플라인이 닫힘(음수) 또는 열림(양수);<br>- 절대값: Thickness + 1. |
| <b>스플라인 데이터 #2</b> <i>색상</i> | 입력 스플라인의 추가 데이터#2 색상 이미지의 RGBA 채널로 인코딩됩니다.<br><b>R</b> - 탄젠트 X<br><b>G</b> - 탄젠트 Y<br><b>B</b> - 미사용<br><b>A</b> - 미사용 |
| <b>스플라인 양 #2</b> <i>정수</i> | 입력 스플라인 수가 #2. |
| <b>시작 접선 길이 곡선</b> <i>회색 음영</i>(&#39;Bridge Splines Type&#39;이 &#39;입방 베지어&#39;로 설정된 경우 사용 가능) | 첫 번째 픽셀 행 값을 사용하여 곡선을 설명하는 이미지입니다.<br>이 입력은 스플라인 #1을 따라 생성된 각 스플라인의 시작점에 대한 &#39;끝&#39; 접선의 길이를 제어하는 데 사용됩니다.<br>곡선 노드를 사용하여 곡선을 만들 수 있습니다. |
| <b>탄젠트 회전 곡선 시작</b> <i>회색 음영</i>(&#39;Bridge Splines Type&#39;이 &#39;입방 베지어&#39;로 설정된 경우 사용 가능) | 첫 번째 픽셀 행 값을 사용하여 곡선을 설명하는 이미지입니다.<br>이 입력은 스플라인 #1을 따라 생성된 각 스플라인의 시작점에 대한 &#39;끝&#39; 접선의 회전을 제어하는 데 사용됩니다.<br>이미지의 회색 음영 값은 회전 수를 나타냅니다.<br>곡선 노드를 사용하여 곡선을 만들 수 있습니다. |
| <b>끝 접선 길이 곡선</b> <i>회색 음영</i>(&#39;Bridge Splines Type&#39;이 &#39;입방 베지어&#39;로 설정된 경우 사용 가능) | 첫 번째 픽셀 행 값을 사용하여 곡선을 설명하는 이미지입니다.<br>이 입력은 스플라인 #2을 따라 생성된 각 스플라인의 끝점에 대한 &#39;인&#39; 접선의 길이를 제어하는 데 사용됩니다.<br>곡선 노드를 사용하여 곡선을 만들 수 있습니다. |
| <b>끝 탄젠트 회전 곡선</b> <i>회색 음영</i>(&#39;Bridge Splines Type&#39;이 &#39;입방 베지어&#39;로 설정된 경우 사용 가능) | 첫 번째 픽셀 행 값을 사용하여 곡선을 설명하는 이미지입니다.<br>이 입력은 스플라인 #2를 따라 생성된 각 스플라인의 끝점에 대한 &#39;인&#39; 접선의 회전을 제어하는 데 사용됩니다.<br>이미지의 회색 음영 값은 회전 수를 나타냅니다.<br>곡선 노드를 사용하여 곡선을 만들 수 있습니다. |

<a name="outputs"></a>

## 출력

|  |  |
|:---|:---|
| <b>미리 보기</b> <i>회색 음영</i> | 출력 미리 보기가 회색 음영 이미지로 분할됩니다. |
| <b>스플라인 코드</b> <i>색상</i> | 색상 이미지의 RGBA 채널로 인코딩된 출력 스플라인의 좌표입니다.<br><b>R</b> - X 위치<br><b>G</b> - Y 위치<br><b>B</b> - Height<br><b>A</b> - 압축된 데이터:<br>- 기호: 스플라인이 닫힘(음수) 또는 열림(양수);<br>- 절대값: Thickness + 1. |
| <b>스플라인 데이터</b> <i>색상</i> | 색상 이미지의 RGBA 채널로 인코딩된 출력 스플라인의 추가 데이터입니다.<br><b>R</b> - 탄젠트 X<br><b>G</b> - 탄젠트 Y<br><b>B</b> - 미사용<br><b>A</b> - 미사용 |
| <b>스플라인 양</b> <i>정수</i> | 출력 스플라인의 수입니다. |

<a name="parameters"></a>

## 매개변수

|  |  |
|:---|:---|
| <b>브리지 스플라인 양</b> <i>정수</i> | 스플라인을 따라 생성된 스플라인 수가 #1스플라인&rbrack; #2. |
| <b>Bridge 스플라인 유형</b> <i>정수</i> | 생성되는 스플라인 유형:<br><br>- 선형: 시작점에서 끝점까지의 직선 스플라인;<br>- 큐빅 베지어: 시작점에서 끝점까지의 곡선 스플라인(곡선은 시작점과 끝점의 길이 및 각도로 제어됨). |
| <b>스플라인 시작 #1</b> <i>부동</i> | 스플라인이 생성된 위치에서 스플라인 #1을 따라 위치를 오프셋합니다. 이 값은 스플라인 #1의 정규화된 길이입니다.<br>값이 높을수록 같은 수의 스플라인이 더 촘촘하게 패킹됩니다. |
| <b>스플라인 시작 #2</b> <i>부동</i> | 스플라인이 생성된 위치에서 스플라인 #2을 따라 위치를 오프셋합니다. 이 값은 스플라인 #2의 정규화된 길이입니다.<br>값이 높을수록 같은 수의 스플라인이 더 촘촘하게 패킹됩니다. |
| <b>스플라인 끝 #1</b> <i>부동</i> | 스플라인을 따라 스플라인이 #1 위치까지 위치를 오프셋합니다. 이 값은 스플라인 #1의 정규화된 길이입니다.<br>값이 낮을수록 동일한 수의 스플라인이 더 촘촘하게 패킹됩니다. |
| <b>스플라인 끝 #1</b> <i>부동</i> | 스플라인을 따라 스플라인이 #2 위치까지 위치를 오프셋합니다. 이 값은 스플라인 #2의 정규화된 길이입니다.<br>값이 낮을수록 동일한 수의 스플라인이 더 촘촘하게 패킹됩니다. |
| <b>오프셋 스플라인 #1</b> <i>부동</i> | 스플라인 간격을 따라 모든 스플라인의 시작점에 오프셋을 #1. 이 값은 스플라인 #1의 정규화된 길이입니다.<br>스플라인의 시작 또는 끝 부분을 만나는 스플라인은 남아 있습니다. |
| <b>오프셋 스플라인 #2</b> <i>부동</i> | 스플라인 간격을 따라 모든 스플라인의 시작점에 오프셋을 #2. 이 값은 스플라인 #2의 정규화된 길이입니다.<br>스플라인의 시작 또는 끝 부분을 만나는 스플라인은 남아 있습니다. |
| <b>오프셋 임의 시작</b> <i>부동</i> | 스플라인 간격을 따라 각 스플라인의 시작점에 임의 오프셋을 #1. 이 값은 스플라인 #1의 스플라인 간의 정규화된 거리입니다.<br>0으로 두면 스플라인이 시작 스플라인 지점과 끝 스플라인 #1 지점 사이#1 균등하게 위치합니다. |
| <b>오프셋 임의 끝</b> <i>부동</i> | 스플라인 간격을 따라 각 스플라인의 끝점에 임의 오프셋을 #2. 이 값은 스플라인 #2의 스플라인 간의 정규화된 거리입니다.<br>0으로 두면 스플라인이 시작 스플라인 지점과 끝 스플라인 #2 지점 사이#2 균등하게 위치합니다. |
| <b>접선 길이 시작</b> <i>부동</i>(&#39;Bridge 스플라인 유형&#39;이 &#39;입방 베지어&#39;로 설정된 경우 사용 가능) | 생성된 모든 스플라인의 스플라인 시작점에 대한 &#39;아웃&#39; #1의 길이입니다. |
| <b>접선 길이 끝</b> <i>부동</i>(&#39;Bridge 스플라인 유형&#39;이 &#39;입방 베지어&#39;로 설정된 경우 사용 가능) | 생성된 모든 스플라인의 스플라인 끝점에 대한 &#39;인(in)&#39; 탄젠트 #2. |
| <b>접선 회전 시작</b> <i>부동</i>(&#39;Bridge 스플라인 유형&#39;이 &#39;입방 베지어&#39;로 설정된 경우 사용 가능) | 생성된 모든 스플라인의 스플라인 시작점에 대한 &#39;아웃&#39; #1의 회전입니다.<br>값은 회전 수입니다. |
| <b>접선 회전 끝</b> <i>부동</i>(&#39;Bridge 스플라인 유형&#39;이 &#39;입방 베지어&#39;로 설정된 경우 사용 가능) | 생성된 모든 스플라인의 스플라인 #2 끝점에 대한 &#39;인&#39; 탄젠트의 회전입니다.<br>값은 회전 수입니다. |
| <b>미리 보기</b> |  |
| <b>세그먼트 양</b> <i>정수</i> | [미리 보기] 출력에서 스플라인 시각화를 그리는 데 사용되는 선분의 수를 조정합니다. 값이 높을수록 선이 더 매끄러워집니다. |
| <b>방향 도우미 표시</b> <i>부울</i> | 미리 보기 출력에서 스플라인의 시작 부분에 점을 표시하고 끝 부분에 화살표를 표시합니다. |
| <b>Thickness 봉투 표시</b> <i>부울</i> | 스플라인 Thickness 모서리에 추가 선을 표시합니다. |
| <b>Thickness(px)</b> <i>부동</i> | 미리 보기 출력에서 스플라인 시각화의 Thickness을 픽셀 단위로 조정합니다. |
