## 설명

입력 마스터 스플라인을 따라 스플라인을 배치합니다.

산란은 스플라인의 분산 방식을 제어할 수 있는 심층 사용자 정의 옵션을 제공하며, 간단한 직선 스플라인 또는 사용자 정의 스플라인을 제어할 수 있습니다.

노드를 사용하면 [스플라인 매퍼](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/spline-mapper-grayscale/spline-mapper-grayscale.md) 노드를 사용하여 색상과 이미지를 매핑하기 위한 복잡한 구조를 만들거나 [스플라인 상의 산란](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/scatter-spline-grayscale/scatter-on-spline-grayscale.md) 노드를 사용하여 모양을 배치하기 위한 뼈대로 사용할 수 있습니다.

| <b>사용자 지정 스플라인 데이터</b> *색상* | 색상 이미지의 RGBA 채널에 인코딩된 사용자 정의 스플라인의 추가 데이터: <b>R</b> - 탄젠트 X <b>G</b> - 탄젠트 Y <b>B</b> - 탄젠트 Z <b>A</b> - 미사용 |

## 매개변수

|  |  |
| --- | --- |
| <b>측면</b> *정수* | &#39;앞으로&#39;가 *부모* 스플라인의 방향임을 고려하여 상위 스플라인의 어느 측면에 분산되어야 하는지 제어합니다. 왼쪽: 스플라인을 왼쪽에 배치합니다.   오른쪽 스플라인을 오른쪽에 배치합니다.   왼쪽 + 오른쪽 양 측면에 스플라인을 배치합니다.   왼쪽 / 오른쪽 - 대체 배치가 왼쪽이나 오른쪽으로 스플라인(예: 양쪽 모두)   왼쪽 / 오른쪽 - 각 스플라인에 대해 측면을 임의로 선택합니다. |
| <b>금액 모드</b> *정수* | 각 모 스플라인에 흩어진 스플라인의 양에 영향을 주는 모 스플라인을 따라 스플라인을 분산하는 방법: 스플라인당 고정 수량 일정한 간격의 스플라인이 분산됩니다.   간격 지정된 짝수 간격에 맞게 스플라인의 양이 자동으로 조정됩니다.   두 경우 모두 첫 번째와 마지막 흩어진 스플라인이 각 모 스플라인의 시작과 끝에 각각 정확히 떨어집니다. |
| <b>스플라인당 스플라인 양</b> *정수* | 각 모 스플라인을 따라 분산되는 스플라인의 간격이 일정합니다. |
| <b>스플라인 간격</b> *부동* | 각 모 스플라인의 시작과 끝에 첫 번째 스플라인과 마지막 스플라인을 계속 연결하는 동안 스플라인의 간격을 지정해야 하는 모 스플라인을 따른 최소 거리입니다. |
| <b>스플라인 유형</b> *정수* | 부모 스플라인에 분산할 스플라인 유형을 선택합니다. 스트레이트 단순 스트라인   사용자 정의 스플라인 <b>사용자 정의 스플라인</b> 입력에 제공되는 스플라인입니다. 목록에 여러 스플라인이 함께 추가될 때 지원됩니다. |
| <b>사용자 지정 스플라인 선택</b> *정수* | 목록에 함께 첨부된 여러 사용자 정의 스플라인을 사용하는 경우 이 매개 변수를 사용하면 이러한 스플라인이 분산에서 분산되는 방식을 선택할 수 있습니다.   전체 목록 모든 스플라인이 그룹으로 함께 흩어집니다.   순차 각 개별 스플라인은 순서대로 분산되며 목록 주위를 반복합니다.   임의(Random) 임의의 스플라인이 흩어져 있는 모든 스플라인의 목록에서 선택됩니다. |
| <b>시작</b> *부동* | 산포가 시작되는 모 스플라인의 시작점에서 점을 오프셋합니다.  값은 각 모 스플라인의 표준화된 길이입니다. |
| <b>종료</b> *부동* | 분산이 끝나는 모 스플라인의 시작점에서 점을 오프셋합니다.  값은 각 모 스플라인의 표준화된 길이입니다. |
| <b>방향 뒤집기</b> *부울* | 흩어진 스플라인의 방향을 반전합니다. |
| <b>왼쪽/오른쪽 대칭 모드</b> *정수* | 부모 스플라인의 각각의 면에 산재된 스플라인에 적용되는 대칭의 방법.   대칭 없음 대칭 없음, 스플라인이 각 측면에 배치됩니다.   왼쪽 대칭 왼쪽의 스플라인은 부모 스플라인에 상대적으로 오른쪽의 스플라인과 대칭됩니다.   오른쪽 대칭 오른쪽의 스플라인은 왼쪽 스플라인과 상대적으로 대칭입니다. |
| <b>왼쪽/오른쪽 임의 링크</b> *부울* | 임의 회전, 임의 비율 등을 사용할 때 모 스플라인의 각 측면에 있는 스플라인이 같은 값을 사용할지 여부를 제어합니다. 즉, *- False:* 각 스플라인은 별도의 임의 값을 사용합니다. *- True:* 두 스플라인은 동일한 임의 값을 공유합니다. |
| <b>스플라인 피벗 모드</b> *정수* | 회전 및 배율 조정에 영향을 주는 흩어진 스플라인의 피벗을 배치하는 방법을 설정합니다.   피벗은 *항상 부모 스플라인*&#x200B;에 배치되고 해당 컨트롤은 흩어진 스플라인에 영향을 줍니다. 즉, 피벗은 이동하지 않으며, 해당 피벗에 상대적으로 이동하고 크기가 조절되는 스플라인입니다.   스플라인을 따라 위치(Position along spline) 흩어진 스플라인을 따라 피벗을 이동합니다.   절대 위치 피벗의 임의의 위치를 설정합니다. |
| <b>스플라인을 따라 피벗 위치</b> *부동* | 흩어져 있는 스플라인을 따라 피벗의 정규화된 위치로, 여기서 0은 시작이고 1은 끝입니다.   피벗은 흩어진 스플라인의 *방향*&#x200B;을 따르며 스플라인의 방향이 변경되어 피벗의 위치와 부모 스플라인에 대한 회전을 상대적으로 유지할 수 있습니다. |
| <b>피벗 절대 위치</b> *Float2* | 피벗의 UV 공간에서 위치입니다. |
| <b>정사각형이 아닌 수정</b> *부울* | 스플라인 위치와 Thickness을 조정하여 사각형이 아닌 해상도에서 모양을 유지합니다.   *참고:* 사용자 지정 스플라인을 사용할 때 사용자 지정 스플라인은 *동일한 이미지 비율*&#x200B;을 <b>스플라인의 산란 스플라인</b> 노드와 사용해야 합니다. |

+++크기

|  |  |
| --- | --- |
| <b>스플라인 배율</b> *부동* | 모든 스플라인의 크기에 대한 전역 컨트롤입니다. 여기서 1은 원래 전체 크기입니다.   비율은 스플라인의 피벗에 상대적으로 적용됩니다. <b>스플라인 피벗</b> 매개 변수를 사용하여 피벗 위치를 오프셋할 수 있습니다. |
| <b>스플라인 배율 무작위</b> *부동* | 스플라인의 크기를 줄이기 위해 지정된 값까지 무작위 승수를 적용합니다. |
| <b>맵 입력 승수 크기 조절</b> *부동* | <b>지도 크기 조절</b> 입력의 강도를 제어합니다. 이 지도는 현재 패턴 크기에 대한 승수 역할을 한다.   이 맵의 효과는 <b>크기</b> 그룹의 다른 매개 변수와 결합됩니다. |
| <b>비율 맵 입력 샘플링 모드</b> *정수* | <b>비율 맵</b>의 값을 스플라인에 매핑하는 방법: 텍스처 공간 텍스처의 UV 좌표를 사용하여 텍스처에 배치할 경우 해당 값이 스플라인에 적용됩니다. 이는 스플라인을 따라 가로로 &#39;제자리&#39; 스플라인에 값을 효과적으로 적용합니다. 값은 인코딩된 스플라인의 좌표에 직접 적용됩니다(<b>스플라인 좌표</b> 입력 참조). 여기서 각 행은 위에서 아래 Hor까지 다른 스플라인에 적용됩니다. 스플라인을 따라(랜드). 오프셋 X) 값은 인코딩된 스플라인의 좌표에 직접 적용됩니다(<b>스플라인 좌표</b> 입력 참조). 각 스플라인(즉, <b>스플라인 좌표</b>의 각 행)에 대한 <b>배율 맵</b>의 임의의 수평 오프셋이 적용됩니다. 스플라인을 따라(랜드). 오프셋 Y) 값은 인코딩된 스플라인의 좌표에 직접 적용됩니다(<b>스플라인 좌표</b> 입력 참조). 각 스플라인(즉, <b>스플라인 좌표</b>의 각 행)에 대한 <b>배율 맵</b>의 임의 수직 오프셋이 적용됩니다. |
| <b>감쇠 시작/종료</b> *Float2* | 스플라인의 비율을 조정할 때 스플라인의 중간점에서 <b>시작</b> 및 <b>종료</b>까지의 거리에 있는 인자입니다.   이는 스플라인의 가장자리에 가까운 스플라인의 크기가 감소함을 의미합니다. |

+++위치

|  |  |
| --- | --- |
| <b>로컬 오프셋</b> *Float2* | 모 스플라인의 탄젠트(평행) 및 수직(수직)을 따라 스플라인의 위치에 오프셋을 적용합니다. |

| <b>스플라인 오프셋</b> *부동* | 부모 스플라인을 따라 스플라인에 위치 오프셋을 적용합니다. |
| <b>임의 오프셋 범위</b> *정수* | 상위 스플라인을 따라 흩어진 스플라인에 적용되는 임의 오프셋 범위를 설정합니다.   간격 각 스플라인 분산 간격 *사이*&#x200B;의 범위입니다.   부모 스플라인 범위는 부모 스플라인의 *전체 길이*&#x200B;에 걸쳐 있습니다. |
| <b>스플라인 상의 임의 오프셋</b> *부동* | 모 스플라인을 따라 스플라인에 추가 위치 오프셋을 적용합니다. |
| <b>Thickness 오프셋</b> *부동* | 상위 스플라인의 수직을 따라 상위 스플라인의 Thickness에 이르기까지 흩어진 스플라인에 오프셋을 적용합니다.   1의 값을 효과적으로 사용하면 흩어진 스플라인을 부모 스플라인의 엔벌로프의 *표면*&#x200B;에 배치할 수 있습니다. |

+++회전

|  |  |
| --- | --- |
| <b>사용자 지정 스플라인 정렬</b> *정수* | 모 스플라인의 사용자 정의 스플라인의 초기 방향을 제어합니다.   첫 번째 점 탄젠트 스플라인은 첫 번째 점의 탄젠트에 따라 정위됩니다. 즉, 첫 번째 점이 설정한 방향으로 모 스플라인을 벗어납니다.   이미지 공간 스플라인을 나타내는 이미지가 상위 스플라인에 있는 것처럼 위치 또는 방향을 추가로 조정하지 않고 원래 나타나는 대로 스플라인이 배치됩니다. |
| <b>회전 모드</b> *정수* | 흩어진 스플라인의 초기 방향을 설정합니다.   스플라인부터 스플라인이 해당 위치의 부모 스플라인의 *표준*&#x200B;과 일치하도록 지정됩니다.   절대 스플라인은 부모 스플라인의 방향에 관계없이 모두 *같은 방법*&#x200B;으로 향합니다. |
| <b>회전</b> *부동* | 회전 수로 피벗을 중심으로 스플라인을 회전합니다. <b>스플라인 피벗</b> 매개 변수를 사용하여 피벗 위치를 오프셋할 수 있습니다. |
| <b>회전 무작위</b> *부동* | 피벗 주위의 스플라인에 회전 수로 추가 임의 회전을 적용합니다. <b>스플라인 피벗</b> 매개 변수를 사용하여 피벗 위치를 오프셋할 수 있습니다. |
| <b>왼쪽/오른쪽 각도</b> *부동* | 모 스플라인의 각 측면에 있는 스플라인에 적용되는 대칭 회전 각도를 회전 수로 제어합니다. |
| <b>왼쪽/오른쪽 각도 무작위</b> *부동* | 모 스플라인의 양쪽에 있는 스플라인에 임의의 대칭 회전 양을 회전 수로 추가합니다. |
| <b>회전 맵 입력 승수</b> *부동* | <b>회전 맵</b> 입력의 강도를 제어합니다. 이 맵은 현재 패턴 회전을 위한 승수 역할을 한다.   이 맵의 효과는 <b>회전</b> 그룹의 다른 매개 변수와 결합됩니다. |
| <b>회전 맵 입력 샘플링 모드</b> *정수* | <b>회전 맵</b>의 값을 스플라인에 매핑하는 방법: 텍스처 공간 텍스처의 UV 좌표를 사용하여 텍스처에 배치할 경우 해당 값이 스플라인에 적용됩니다. 이는 스플라인의 &#39;제자리&#39;, 스플라인을 따라 수평(Horizontal along spline)에 값을 효과적으로 적용합니다. 값은 인코딩된 스플라인의 좌표에 직접 적용됩니다(<b>스플라인 좌표</b> 입력 참조). 여기서 각 행은 위에서 아래로 다른 스플라인에 적용됩니다. 스플라인을 따라(랜드). 오프셋 X) 값은 인코딩된 스플라인의 좌표에 직접 적용됩니다(<b>스플라인 좌표</b> 입력 참조). 각 스플라인의 경우(즉, <b>스플라인 좌표</b>의 각 행) <b>회전 맵</b>에서 임의의 수평 오프셋이 적용됩니다.   호르 스플라인을 따라(랜드). 오프셋 Y) 값은 인코딩된 스플라인의 좌표에 직접 적용됩니다(<b>스플라인 좌표</b> 입력 참조). 각 스플라인의 경우(즉, <b>스플라인 좌표</b>의 각 행)<b></b>에 대해 <b>회전 맵</b>에서 임의의 수직 오프셋을 사용합니다. |
| <b>회전 맵 입력 영향</b> *정수* | <b>회전 맵</b>의 영향을 받는 회전 매개 변수를 선택합니다. 스플라인 회전 맵은 스플라인의 전역 회전을 시계 방향으로 영향을 줍니다.   왼쪽/오른쪽 각도 맵은 <b>왼쪽/오른쪽</b> 스플라인의 대칭 회전에 영향을 줍니다. |
