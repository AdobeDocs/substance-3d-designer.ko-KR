## 설명

입력 마스터 스플라인을 따라 스플라인을 배치합니다.

산란은 스플라인의 분산 방식을 제어할 수 있는 심층 사용자 정의 옵션을 제공하며, 간단한 직선 스플라인 또는 사용자 정의 스플라인을 제어할 수 있습니다.

노드를 사용하면 [스플라인 매퍼](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/spline-mapper-grayscale/spline-mapper-grayscale.md) 노드를 사용하여 색상과 이미지를 매핑하기 위한 복잡한 구조를 만들거나 [스플라인 상의 산란](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/scatter-spline-grayscale/scatter-on-spline-grayscale.md) 노드를 사용하여 모양을 배치하기 위한 뼈대로 사용할 수 있습니다.

| <b>사용자 지정 스플라인 데이터</b> *색상* | 색상 이미지의 RGBA 채널에 인코딩된 사용자 정의 스플라인의 추가 데이터: <b>R</b> - 탄젠트 X <b>G</b> - 탄젠트 Y <b>B</b> - 탄젠트 Z <b>A</b> - 미사용 |

| <b>지도 크기 조절</b> *회색 음영* | 흩어진 스플라인의 비율을 제어하는 회색 음영 맵  이 맵의 효과는 <b>비율 맵 입력 승수</b> 매개 변수에 의해 제어되며 <b>크기</b> 그룹의 다른 매개 변수와 결합됩니다. |

## 매개변수

|  |  |
|:---|:---|
| <b>측면</b> *정수* | &#39;앞으로&#39;가 *부모* 스플라인의 방향임을 고려하여 스플라인의 어느 면에 분산되어야 하는지 제어합니다.<br><br>- <b>왼쪽</b> 스플라인을 왼쪽에 배치합니다.<br>- <b>오른쪽</b> 스플라인을 오른쪽에 배치합니다.<br>- <b>왼쪽 + 오른쪽</b> 스플라인을 양쪽에 배치합니다.<br>- <b>왼쪽/오른쪽 - 대체</b> 스플라인을 왼쪽 및 오른쪽(예: 모든 다른 면)으로 배치합니다.<br>- <b>왼쪽/오른쪽 - 무작위</b> 각 스플라인에 대해 무작위 면을 선택합니다. |
| <b>금액 모드</b> *정수* | 스플라인을 상위 스플라인을 따라 분산하는 방법으로, 각 상위 스플라인에 분산된 스플라인의 양에 영향을 미칩니다.<br><br>- <b>스플라인당 고정된 양</b> 일정한 간격의 스플라인이 분산됩니다.<br>- <b>간격</b> 지정된 균일 간격에 맞게 스플라인의 양이 자동으로 조정됩니다.<br><br>두 경우 모두 흩어진 첫 번째 스플라인과 마지막 스플라인이 각 상위 스플라인의 시작과 끝에 정확히 떨어집니다. |
| <b>스플라인당 스플라인 양</b> *정수* | 각 모 스플라인을 따라 분산되는 스플라인의 간격이 일정합니다. |
| <b>스플라인 간격</b> *부동* | 각 모 스플라인의 시작과 끝에 첫 번째 스플라인과 마지막 스플라인을 계속 연결하는 동안 스플라인의 간격을 지정해야 하는 모 스플라인을 따른 최소 거리입니다. |
| <b>스플라인 유형</b> *정수* | 부모 스플라인에 분산할 스플라인 유형을 선택합니다.<br><br>- <b>스트레이트</b> 간단한 스트레이트 스플라인<br>- <b>사용자 지정 스플라인</b> <b>사용자 지정 스플라인</b> 입력에 제공되는 스플라인입니다. 목록에 여러 스플라인이 함께 추가될 때 지원됩니다. |
| <b>사용자 지정 스플라인 선택</b> *정수* | 목록에 함께 추가된 여러 사용자 정의 스플라인을 사용하는 경우 이 매개 변수를 사용하면 이러한 스플라인이 분산되는 방식을 선택할 수 있습니다.<br><br>- <b>전체 목록</b> 모든 스플라인이 그룹으로 함께 분산됩니다.<br>- <b>순차</b> 각 개별 스플라인이 순서대로 분산되어 목록을 반복합니다.<br>- <b>임의</b> 분산된 모든 스플라인에 대해 목록에서 임의 스플라인이 선택됩니다. |
| <b>시작</b> *부동* | 산포가 시작되는 모 스플라인의 시작점에서 점을 오프셋합니다. 값은 각 모 스플라인의 표준화된 길이입니다. |
| <b>종료</b> *부동* | 분산이 끝나는 모 스플라인의 시작점에서 점을 오프셋합니다. 값은 각 모 스플라인의 표준화된 길이입니다. |
| <b>방향 뒤집기</b> *부울* | 흩어진 스플라인의 방향을 반전합니다. |
| <b>왼쪽/오른쪽 대칭 모드</b> *정수* | 부모 스플라인의 양쪽에 흩어져 있는 스플라인에 적용되는 대칭 방법입니다.<br><br>- <b>사용 안 함</b> 대칭이 적용되지 않고 단순 회전을 사용하여 각 측면에 스플라인을 배치합니다.<br>- <b>왼쪽 대칭</b> 왼쪽의 스플라인은 부모 스플라인의 오른쪽에 상대적으로 오른쪽에 있는 스플라인과 대칭됩니다.<br>- <b>오른쪽 대칭</b> 오른쪽의 스플라인은 부모 스플라인의 왼쪽에 상대적으로 왼쪽에 있는 스플라인과 대칭됩니다. |
| <b>왼쪽/오른쪽 임의 링크</b> *부울* | 임의 회전, 임의 비율 등을 사용할 때 모 스플라인의 각 측면에 있는 스플라인이 같은 값을 사용할지 여부를 제어합니다. 즉, <br><br>- <i>거짓:</i> 각 스플라인은 별도의 임의 값을 사용합니다<br>- <i>참:</i> 두 스플라인은 동일한 임의 값을 공유합니다 |
| <b>스플라인 피벗 모드</b> *정수* | 회전 및 배율 조정에 영향을 주는 흩어진 스플라인의 피벗을 배치하는 방법을 설정합니다.<br>피벗은 *항상 부모 스플라인*&#x200B;에 놓이고 해당 컨트롤은 흩어진 스플라인에 영향을 줍니다. 즉, 피벗은 이동하지 않으며, 상대적으로 해당 피벗으로 이동하고 크기가 조절되는 분산 스플라인입니다.<br><br>- <b>스플라인을 따라 위치</b> 분산 스플라인을 따라 피벗을 이동합니다.<br>- <b>절대 위치</b> 피벗에 대한 임의의 위치를 설정합니다. |
| <b>스플라인을 따라 피벗 위치</b> *부동* | 흩어져 있는 스플라인을 따라 피벗의 정규화된 위치로, 여기서 0은 시작이고 1은 끝입니다.<br>피벗은 흩어진 스플라인의 *방향*&#x200B;을 따르며, 스플라인의 방향이 변경되어 피벗의 위치와 회전을 부모 스플라인에 상대적으로 유지할 수 있습니다. |
| <b>피벗 절대 위치</b> *Float2* | 피벗의 UV 공간에서 위치입니다. |
| <b>정사각형이 아닌 수정</b> *부울* | 스플라인 위치와 Thickness을 조정하여 정사각형이 아닌 해상도에서 모양을 유지합니다.<br><i>참고:</i> 사용자 지정 스플라인을 사용할 때는 사용자 지정 스플라인이 <b>스플라인의 산란 스플라인</b> 노드와 *동일한 이미지 비율*&#x200B;을 사용해야 합니다. |
| <b>크기</b> |  |
| <b>스플라인 배율</b> *부동* | 모든 스플라인의 크기에 대한 전역 컨트롤입니다. 여기서 1은 원래 전체 크기입니다.<br>스플라인의 피벗에 상대적으로 크기 조절이 적용됩니다. <b>스플라인 피벗</b> 매개 변수를 사용하여 피벗 위치를 오프셋할 수 있습니다. |

| <b>Thickness(px)</b> *부동* | <b>미리 보기</b> 출력에서 스플라인 시각화의 Thickness을 픽셀 수로 조정합니다. |
| <b>세그먼트 양</b> *정수* | <b>미리 보기</b> 출력에서 스플라인 시각화를 그리는 데 사용되는 세그먼트 수를 조정합니다. 값이 높을수록 선이 더 매끄러워집니다. |
| <b>배경 강도</b> *부동* | <b>미리 보기</b> 출력 시각화에서 <b>미리 보기</b> 입력의 강도입니다. |
