# 노드 라이브러리

[Atomic nodes](../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md) 외에도 Designer에는 많은 범주로 구분되는 사전 제작 [그래프 인스턴스](../../../compositing-graphs/creating-compositing-gra/graph-instances-sub-gra/graph-instances-sub-graphs.md) 라이브러리도 제공됩니다. 200개 이상의 다양한 제품이 있습니다. 일부는 매우 자주 유용하며 일부는 매우 구체적인 사용 사례를 위해 고안되었습니다.이 문서 영역에서는 모든 라이브러리 노드에 대해 설명하고 시작하기 좋은 노드에 대한 포인터와 팁을 제공합니다.

Designer의 라이브러리 패널에 현재 문서화되어 있는 것보다 더 많은 범주가 표시됩니다. 특히 MDL 노드가 누락되어 있으며, 향후 추가될 수 있습니다.
