# Substance 모델 그래프 기능이 없습니다.

## 서비스 종료

Substance 모델 그래프는 파라메트릭 모델링에 처음 참여했으며 나중에 Substance 3D Designer 버전 <b>13.0.0</b>에서 <b>중단</b>되었습니다.

버전 <b>12.4.1</b>은(는) Substance 모델 그래프를 지원하는 Designer의 *마지막* 버전입니다. 따라서 해당 기능의 사용자는 상위 버전으로 업데이트해서는 안 됩니다.
