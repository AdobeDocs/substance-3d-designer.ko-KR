[핀]은 그래프의 특정 위치를 빠르게 뛰어넘을 수 있는 도우미입니다.

해당 <b>설명</b> 속성을 사용하여 사용자 지정 레이블을 설정할 수 있습니다.

## 핀 만들기

다음과 같은 방법으로 핀을 만들 수 있습니다.

+++노드 메뉴
그래프 보기에서 <b>스페이스바</b>를 눌러 <b>노드 메뉴</b>를 열고 목록에서 &#39;고정&#39; 항목을 선택합니다.

항목을 표시하고 더 빠르게 찾으려면 검색 필드에 &#39;핀&#39;을 입력합니다.

+++

+++단축키
키보드 단축키가 [환경 설정](../../../../interface/preferences-window/preferences-window.md)의 &#39;고정&#39; 항목에 매핑되어 있으면 그래프 보기에 포커스가 있을 때 해당 단축키를 누릅니다.

+++

+++상황별 메뉴
그래프 보기에서 빈 공간에서 <b>RMB</b>를 누르고 <b>핀 추가</b> 옵션을 선택합니다.

+++

+++그래프 도구 모음
[그래프 보기] 도구 모음의 <b>노드 팔레트</b>에서 &#39;고정&#39; 단추를 클릭합니다.

+++

+++라이브러리
라이브러리에서 <b>그래프 항목</b> 범주를 선택한 다음 &#39;고정&#39; 항목을 그래프 보기로 끌어 놓습니다.

+++

>[!TIP]
>
> 핀이 만들어지면 &#39;설명&#39; 속성에 자동으로 포커스가 추가되므로 핀의 텍스트를 즉시 편집할 수 있습니다.

## 핀으로 이동

모든 그래프 유형에서 <b>F2</b>을 누르면 해당 그래프의 모든 핀이 생성 순서대로 회전합니다.

현재 확대/축소 레벨에서 뷰포트에 핀이 배치됩니다.
