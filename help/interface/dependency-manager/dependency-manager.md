# 종속성 관리자

<b>종속성 관리자</b>를 사용하면 패키지의 모든 종속성을 보고 문제가 발생한 경우 찾아서 복구할 수 있습니다.

탐색기에서 패키지를 마우스 오른쪽 버튼으로 클릭하고 컨텍스트 메뉴에서 &#39;종속성 관리자&#39; 옵션을 선택하여 액세스할 수 있습니다.
