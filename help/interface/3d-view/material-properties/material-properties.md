# 재질 속성

[3D 보기](../../../interface/3d-view/3d-view.md)는 *셰이더*라는 프로그램을 사용하여 모델의 표면을 렌더링합니다. 셰이더는 재질을 정의합니다
모델 모양의 다양한 측면에 영향을 주는 속성 목록을 사용하여 모델에 적용됩니다.

3D 보기의 **재질** 메뉴를 사용하면 장면의 각 재질에 사용할 셰이더를 확인할 수 있습니다.

<a name="openpbr"></a>

## OpenPBR

Designer에서는 기본적으로 비등방성과 같은 여러 복잡한 효과를 지원하는 [OpenPBR](https://academysoftwarefoundation.github.io/OpenPBR/) 재질 모델을 사용합니다.
전송 및 퍼즐.

Designer에 포함된 기본 [그래프 템플릿](../../../compositing-graphs/creating-compositing-gra/creating-a-substance-compositing-graph.md#graph-templates) 및 [재질 샘플](../../../compositing-graphs/creating-compositing-gra/creating-a-substance-compositing-graph.md#material-samples)은 모두 OpenPBR 모델을 기반으로 합니다.

이 셰이더의 속성은 [OpenPBR 매개 변수 참조](https://academysoftwarefoundation.github.io/OpenPBR/#parameterreference)를 따르며 래스터라이저의 *공유*입니다.
GPU 패스트레이서 및 OpenGL [3D 렌더러](../3d-renderers/3d-renderers.md).

### 기존 그래프와의 호환성

## Adobe 표준 재질

Adobe ASM(Standard Material) 모델은 Designer 11.2에 도입되어 Designer의 기본 셰이더입니다
최대 버전 15.1.

Designer이 새로운 기본 모델로 OpenPBR으로 이동했지만 ASM은 여전히 포함되어 있으며 해당 속성도 공유됩니다
래스터라이저에서 GPU 패스트레이서, OpenGL [3D 렌더러](../3d-renderers/3d-renderers.md)를 건너뜁니다.

모델은 [여기](https://experienceleague.adobe.com/en/docs/substance-3d/general-knowledge/asm/adobe-standard-material)에 문서화되어 있습니다.

<a name="usdpreviewsurface"></a>

## UsdPreviewSurface

UsdPreviewSurface 모델의 목적은 호환성을 촉진하는 기본 기능 세트가 있는 재질 미리 보기입니다
usd 및/또는 Hydra를 포함하는 모든 렌더러.

Designer에서 이 재질 모델은 래스터라이저와 GPU 패스트레이서 [3D 렌더러](../3d-renderers/3d-renderers.md)에서만 지원됩니다.

모델은 [여기](https://openusd.org/dev/spec_usdpreviewsurface.html)에 문서화되어 있습니다.
