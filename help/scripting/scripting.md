# 스크립팅

플러그인을 작성함으로써 애플리케이션을 제어할 수 있습니다. 플러그인은 **3.9** 버전을 사용하여 **Python** 스크립팅 언어로 작성할 수 있습니다. 애플리케이션에서 제공되는 Python API를 사용하면 스크립트에서 직접 많은 기능에 액세스하고 사용할 수 있습니다.

[Python](https://www.python.org/)은(는) 많은 산업에서 널리 사용되는 스크립팅 언어입니다. 다른 예시 중에서도 자동화, 워크플로우 가속 및 에셋 관리 도구를 구축하는 데 도움이 됩니다. API 설명서는 **도움말** > **스크립팅 설명서...** 동작을 사용하여 기본 메뉴에서 액세스할 수 있습니다.
