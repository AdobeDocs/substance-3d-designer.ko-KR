# 플러그인 패키지

Python 패키지는 플러그인을 만들어 애플리케이션을 확장하는 데 지원됩니다.

플러그인이 작동하는 데 필요한 모든 것을 포함하는 sdplugin 확장명을 가진 단일 파일입니다. 개발자의 경우 패키지를 통해 플러그인을 간편하게 공유하고 사용자에게 배포할 수 있습니다. 사용자의 경우 패키지를 보다 쉽게 설치하고 관리할 수 있습니다.

## 플러그인 패키지 설치

![플러그인 관리자](plugins-packages.resources/plugins-packages-01.png "플러그인 관리자")

플러그인 패키지는 <b>도구</b> 메뉴의 <b>플러그인 관리자</b>를 사용하여 설치됩니다.

1. <b>설치</b> 단추를 클릭하고 설치할 플러그인 패키지를 선택합니다.
1. 플러그인은 홈 디렉터리의 각 운영 체제에 대한 플러그인의 기본 경로에 설치됩니다
1. 플러그인이 설치되면 자동으로 로드됩니다.
